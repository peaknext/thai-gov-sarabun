# thai-gov-sarabun

AI agent skill สำหรับร่าง **หนังสือราชการไทย** ให้ถูกต้องตาม **ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖**
และที่แก้ไขเพิ่มเติม (ฉบับที่ ๒ พ.ศ. ๒๕๔๘, ฉบับที่ ๓ พ.ศ. ๒๕๖๐, ฉบับที่ ๔ พ.ศ. ๒๕๖๔) ทั้งรูปแบบ ส่วนประกอบ คำขึ้นต้น–คำลงท้าย
เลขที่หนังสือ การลงชื่อ และภาษาราชการ พร้อมสร้างไฟล์ Word (.docx) ที่มีตราครุฑและจัดหน้าตามแบบ

เอกสารอ้างอิง: <https://lawreform.go.th/uploads/files/1678240071-b99vw-cbccp.pdf> (128 หน้า; หน้า 33–118 เป็นภาพสแกน
ซึ่งถอดความทีละหน้าที่ 300 dpi แล้วเก็บไว้ใน `thai-gov-sarabun/references/source/`)

## ติดตั้ง

- **ไฟล์สำเร็จรูป:** `dist/thai-gov-sarabun.skill` — อัปโหลดเป็น skill ใน Claude (Settings → Capabilities → Skills) หรือกดปุ่ม Save skill เมื่อได้รับไฟล์ในแชท
- **Claude Code:** คัดลอกโฟลเดอร์ `thai-gov-sarabun/` ไปไว้ที่ `~/.claude/skills/` (หรือ `.claude/skills/` ในโปรเจกต์)

สคริปต์สร้าง Word ต้องใช้ Python 3 กับ `python-docx` และ `lxml` (`pip install python-docx lxml`); การแปลงเป็น PDF เพื่อดูตัวอย่างต้องมี LibreOffice
ฟอนต์ที่ใช้คือ TH SarabunPSK (หรือ TH Sarabun New) ซึ่งต้องติดตั้งในเครื่องที่เปิดไฟล์

## ใช้งาน

พิมพ์ขอได้ตามปกติ เช่น "ช่วยร่างหนังสือเชิญอธิบดีกรม… มาเป็นวิทยากร…" หรือ "ทำบันทึกข้อความขออนุมัติไปอบรม…" — สกิลจะเลือกชนิดหนังสือ
แสดงร่างในแชท และสร้างไฟล์ .docx ให้

เรียกสคริปต์เองได้:

```bash
cd thai-gov-sarabun
python3 scripts/check_draft.py assets/examples/01-external-letter.json      # ตรวจร่างตามระเบียบ
python3 scripts/build_docx.py assets/examples/01-external-letter.json out.docx --pdf
python3 scripts/thai_docx_fix.py --check out.docx                            # ตรวจการตั้งค่าภาษาไทยของ Word
python3 scripts/thai_format.py weekday 2569-12-05                            # วันในสัปดาห์ / วันหยุด
```

## โครงสร้าง

```
thai-gov-sarabun/
├── SKILL.md                    ขั้นตอนการทำงานและรายการตรวจ
├── references/                 คู่มือ: ชนิดหนังสือ แม่แบบ คำขึ้นต้น–ลงท้าย การลงชื่อ เลขที่ ภาษา หน้ากระดาษ กฎ Word ภาษาไทย
│   ├── templates/              แม่แบบแต่ละชนิด พร้อมวิธีกรอกตามข้อของระเบียบและตัวอย่าง
│   └── source/                 ตัวบทระเบียบและภาคผนวกทั้งเล่ม (ถอดจาก PDF รวมหน้าสแกน)
├── scripts/                    build_docx.py · check_draft.py · thai_docx_fix.py · thai_format.py
├── assets/                     ตราครุฑ (จากแบบที่ ๒๖) และ spec ตัวอย่าง ๑๒ แบบ
└── evals/                      ชุดทดสอบ ๕ กรณี (รูปแบบ claude plugin eval)
```

## ข้อจำกัด

- รหัสพยัญชนะกระทรวงในภาคผนวก ๑ เป็นโครงสร้างเดิม รหัสกระทรวงใหม่ที่ระบุไว้เป็นรหัสตามทางปฏิบัติ ควรยืนยันกับหน่วยงาน
- ระยะขอบ ฟอนต์ และย่อหน้า เป็นแนวปฏิบัติทั่วไป (ระเบียบกำหนดเฉพาะขนาดครุฑ กระดาษ ซอง และชั้นความเร็ว) — ถ้าหน่วยงานมีแบบของตนเองให้ใช้แบบนั้น
- ภาพครุฑตัดจากภาพสแกนในเอกสารอ้างอิง เหมาะกับฉบับร่าง สำหรับพิมพ์ใช้จริงควรใช้ไฟล์ครุฑความละเอียดสูงของหน่วยงาน
- การเช็กวันหยุดรู้จักเฉพาะวันหยุดที่วันที่ตายตัว ยังไม่รวมวันหยุดทางพุทธศาสนาที่เลื่อนตามจันทรคติ
