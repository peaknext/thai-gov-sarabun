# ร่างหนังสือราชการไทยตามระเบียบงานสารบรรณ

สกิลนี้ช่วยร่างหนังสือราชการให้ **ถูกชนิด ถูกแบบ ครบส่วน ใช้คำขึ้นต้น–ลงท้ายถูกฐานะผู้รับ และใช้ภาษาราชการ**
โดยยึดระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖ และที่แก้ไขเพิ่มเติม (ฉบับที่ ๒ ๒๕๔๘, ๓ ๒๕๖๐, ๔ ๒๕๖๔)
ข้อความต้นฉบับทั้งเล่ม (รวมหน้าที่เป็นภาพสแกนซึ่งถอดความแล้ว) อยู่ใน `references/source/`

ผู้ใช้ส่วนใหญ่เป็นเจ้าหน้าที่ที่ต้องการร่างที่ "ส่งต่อให้หัวหน้าตรวจได้เลย" — ร่างที่ดีจึงต้องถูกระเบียบในรายละเอียดเล็ก ๆ
(คำขึ้นต้นคู่กับคำลงท้าย วันที่ใช้ชื่อเต็มของเดือนและ พ.ศ. ลงชื่อแทนใช้คำถูก) เพราะสิ่งเหล่านี้คือจุดที่ผู้ตรวจหนังสือแก้บ่อยที่สุด

## ขั้นตอนการทำงาน

### ๑. ระบุชนิดหนังสือ

อ่าน `references/document-types.md` (ตารางตัดสินใจ) ถ้ายังไม่แน่ใจ สรุปย่อ:

| ต้องการ | ชนิด / ไฟล์แม่แบบ |
|---|---|
| ติดต่อต่างกระทรวง/ต่างกรม หน่วยงานภายนอก เอกชน ประชาชน | หนังสือภายนอก — `references/templates/external-letter.md` |
| ติดต่อภายในกระทรวง ทบวง กรม หรือจังหวัดเดียวกัน / เสนอผู้บังคับบัญชา / ขออนุมัติ | หนังสือภายใน, บันทึก — `references/templates/internal-memo.md` |
| เรื่องไม่สำคัญ: ส่งสำเนา ตอบรับทราบ ขอรายละเอียด เตือนเรื่องค้าง | หนังสือประทับตรา — `references/templates/stamped-letter.md` |
| สั่งการ แต่งตั้ง / วางหลักปฏิบัติ / ข้อบังคับตามกฎหมาย | คำสั่ง ระเบียบ ข้อบังคับ — `references/templates/directives.md` |
| ประกาศ แจ้งความ แถลงการณ์ ข่าว | `references/templates/public-relations.md` |
| หนังสือรับรอง รายงานการประชุม | `references/templates/certificate-and-minutes.md` |
| หนังสือถึงผู้รับจำนวนมาก ใจความเดียวกัน / เวียนแจ้งทุกกอง ทุกกลุ่มงานในหน่วยงาน | หนังสือเวียน — `references/templates/circular.md` |
| หนังสือถึงพระสงฆ์ (อาราธนา นิมนต์ ขออนุญาตใช้สถานที่วัด ถวาย) | `references/templates/to-monks.md` |
| ส่งหนังสือทางอีเมล | `references/templates/email.md` |
| หนังสือภาษาอังกฤษ | `references/english-letters.md` |

ถ้าผู้ใช้ระบุชนิดมาแต่ไม่เหมาะกับสถานการณ์ (เช่น ขอ "บันทึกข้อความ" ถึงหน่วยงานต่างกระทรวง) ให้ทำตามที่ขอแต่บอกสั้น ๆ ว่าตามระเบียบควรเป็นชนิดใดและเพราะอะไร

### ๒. อ่านแม่แบบของชนิดนั้น แล้วรวบรวมข้อมูล

เปิดไฟล์แม่แบบของชนิดที่เลือก — มีโครงร่างตามแบบท้ายระเบียบ วิธีกรอกแต่ละส่วนตามข้อของระเบียบ และตัวอย่าง

ข้อมูลที่มักต้องมี: ส่วนราชการผู้ส่ง (และที่ตั้ง) · ผู้รับ (ตำแหน่ง) · เรื่อง · ข้อเท็จจริง วัน เวลา สถานที่ จำนวนเงิน ·
สิ่งที่ต้องการให้ผู้รับทำ · ผู้ลงนาม (ชื่อ ตำแหน่ง ลงชื่อแทนหรือไม่) · หน่วยงานเจ้าของเรื่องและเบอร์ติดต่อ

- **อย่าแต่งข้อเท็จจริงขึ้นเอง และอย่าเติมจากความจำของคุณ** — ชื่อคน ตำแหน่ง เลขที่หนังสือ รหัสหน่วยงาน ที่อยู่/ถนน/รหัสไปรษณีย์ เบอร์โทร
  ตัวเลขงบประมาณ สถานที่ หัวข้อกำหนดการ ถ้าผู้ใช้ไม่ให้ ให้ใส่ช่องว่างแบบ `[ระบุที่ตั้งส่วนราชการ]` แม้คุณคิดว่ารู้คำตอบ
  (ความจำอาจล้าสมัยหรือผิด และหนังสือราชการเป็นหลักฐานทางราชการ — ช่องว่างที่เห็นชัดปลอดภัยกว่าข้อมูลที่ดูถูกแต่ผิด)
  แล้วบอกผู้ใช้ท้ายคำตอบว่ายังต้องเติมอะไร · ข้อความทั่วไปที่ไม่ใช่ข้อเท็จจริง (เช่น ประโยควัตถุประสงค์ของงาน) เขียนได้ แต่บอกผู้ใช้ให้ปรับ
- เลขทะเบียนหนังสือส่ง (ตัวเลขหลัง `/`) ออกโดยหน่วยสารบรรณกลาง — โดยปกติเว้นไว้ เช่น `ที่ ศธ ๐๒๐๑/`
- ถามผู้ใช้ก่อนร่างเฉพาะเมื่อขาดสิ่งที่เดาไม่ได้และเปลี่ยนรูปหนังสือทั้งฉบับ (เช่น ไม่รู้ว่าผู้รับเป็นใคร หรือวัตถุประสงค์คืออะไร)
  นอกนั้นให้ร่างไปก่อนพร้อมช่องว่าง — ผู้ใช้จะเห็นภาพและเติมได้เร็วกว่าการตอบคำถามทีละข้อ
- ตรวจ **วันในสัปดาห์** ของทุกวันกำหนดในเนื้อความ (กำหนดส่ง วันประชุม วันงาน) ด้วย `python3 scripts/thai_format.py weekday 2569-12-05`
  — ถ้าตรงเสาร์–อาทิตย์หรือวันหยุดราชการ หรือไม่ตรงกับชื่อวันที่ผู้ใช้บอก ให้ใช้วันที่ตามผู้ใช้แต่แจ้งให้พิจารณา (check_draft.py เตือนให้ด้วย)
- วันที่ของหนังสือ: ถ้าผู้ใช้ไม่ระบุ ใช้วันนี้ (`python3 scripts/thai_format.py today`) หรือเว้น `[วัน เดือน ปี]` ถ้าเป็นหนังสือที่จะลงนามภายหลัง

### ๓. เลือกคำขึ้นต้น สรรพนาม คำลงท้าย

ดู `references/salutations.md` — หลักที่ใช้บ่อยที่สุด:
- ๑๕ ตำแหน่งในภาคผนวก ๒ ข้อ ๓.๑ (นายกรัฐมนตรี ประธานรัฐสภา ประธานศาลฎีกา อัยการสูงสุด ฯลฯ) → **กราบเรียน … ขอแสดงความนับถืออย่างยิ่ง**
- บุคคลอื่นทั้งหมด (รวมรัฐมนตรี ปลัดกระทรวง ผู้ว่าราชการจังหวัด อธิบดี ประชาชน) → **เรียน … ขอแสดงความนับถือ**
- พระภิกษุ → นมัสการ … ขอนมัสการด้วยความเคารพ (อย่างสูง/อย่างยิ่ง ตามชั้น — ดู `references/templates/to-monks.md`) · พระราชวงศ์ → ตามตาราง
- หลังคำขึ้นต้นให้ลง **ตำแหน่ง** ผู้รับ ไม่ใช่ชื่อ (เว้นแต่มีถึงตัวบุคคล) · บันทึกข้อความไม่มีคำลงท้าย

### ๔. ร่างเนื้อความด้วยภาษาราชการ

ใช้ `references/writing-style.md` — โครงสร้าง ๓ ส่วน:
1. **เหตุที่มีหนังสือไป** — "ด้วย…" (เรื่องใหม่) / "ตามที่… นั้น" "ตามหนังสือที่อ้างถึง… นั้น" (อ้างเรื่องเดิม) / "เนื่องด้วย…"
2. **จุดประสงค์/รายละเอียด** — "ในการนี้…" "บัดนี้…" "(ส่วนราชการ) พิจารณาแล้วเห็นว่า…" แยกเป็นข้อ ๆ ถ้ามีหลายประการ
3. **ส่วนสรุป** — "จึงเรียนมาเพื่อโปรดทราบ / พิจารณา / พิจารณาอนุมัติ / พิจารณาให้ความอนุเคราะห์…" ให้ตรงกับสิ่งที่ต้องการจริง

ใช้นามส่วนราชการเป็นผู้พูด กระชับ ไม่ใช้ภาษาพูด ใช้ตัวเลขไทยสม่ำเสมอ วันที่เป็น "๒๑ พฤศจิกายน ๒๕๖๙"
ถึงผู้รับระดับ "กราบเรียน" ใช้ "จึง**กราบเรียน**มาเพื่อโปรด…" · ถึงพระสงฆ์ใช้ "จึง**นมัสการ**มาเพื่อโปรด…"

### ๕. ลงชื่อและตำแหน่ง

ดู `references/signing.md` — ชื่อเต็มในวงเล็บพร้อมคำนำนาม `(นายสมชาย ใจดี)` · ลงชื่อแทนใช้ "ปฏิบัติราชการแทน / รักษาราชการแทน …"
ตามด้วยตำแหน่งเจ้าของหนังสือ (ถ้าผู้ใช้ไม่บอกว่าลงชื่อแทน อย่าเติมเอง)

### ๖. ส่งมอบผลงาน

**(ก) แสดงร่างในแชทเสมอ** เป็น code block ที่จัดวางตำแหน่งเลียนแบบหน้ากระดาษ (ครุฑ/ที่/ส่วนราชการ/วันที่/เรื่อง/เรียน/ข้อความ/คำลงท้าย/ชื่อ)
ตามโครงร่างในไฟล์แม่แบบ เพื่อให้ผู้ใช้อ่านทานได้ทันที

**(ข) สร้างไฟล์ .docx** เมื่อผู้ใช้ต้องการไฟล์ หรือเมื่อทำงานในสภาพแวดล้อมที่สร้าง/ส่งไฟล์ได้ (ให้ทำเป็นค่าเริ่มต้นในกรณีนั้น):

```bash
# เขียน spec JSON ตาม references/docx-spec.md (ดูตัวอย่างใน assets/examples/)
python3 scripts/check_draft.py draft.json          # ตรวจตามระเบียบ — แก้ ERROR ทุกข้อก่อน
python3 scripts/build_docx.py draft.json หนังสือ.docx [--pdf]
```

`build_docx.py` จัดหน้า A4 ใส่ครุฑ ๓ ซม./๑.๕ ซม. ตามแบบ ชั้นความเร็วสีแดง ≥ ๓๒ pt ฟอนต์ TH SarabunPSK ๑๖ pt
(หรือ `--font "TH Sarabun New"`) แปลงตัวเลขเป็นเลขไทย และรัน `thai_docx_fix.py` ให้อัตโนมัติ (ต้องมี `python-docx`, `lxml`; `--pdf` ต้องมี LibreOffice)
รายการแบบ "ชื่อ … ตำแหน่งในคณะกรรมการ" ใช้ `\t` คั่นในบรรทัด (ดู `references/docx-spec.md`)
ถ้าติดตั้งไม่ได้ ให้ส่งร่างข้อความพร้อมระบุรูปแบบหน้ากระดาษจาก `references/layout-spec.md` แทน

**ทุกครั้งที่สร้างหรือแก้ .docx ที่มีภาษาไทย (รวมไฟล์ที่ไม่ได้สร้างด้วย build_docx.py)** ต้องเป็นไปตามกฎ ๔ ข้อใน
`references/thai-docx-rules.md` เพื่อให้ Microsoft Word ตัดคำและตรวจตัวสะกดภาษาไทยถูกต้อง:
(1) `w:lang val="en-US" eastAsia="en-US" bidi="th-TH"` ใน docDefaults และทุก style — ไทยอยู่ใน bidi เท่านั้น ห้าม th-TH ใน eastAsia
(2) ทุก run ที่มีอักษรไทยมี `<w:rFonts w:hint="cs"/>` และ `<w:cs/>` (cs อยู่ก่อน em/lang ตามลำดับ schema)
(3) `<w:themeFontLang w:val="en-US" w:eastAsia="en-US" w:bidi="th-TH"/>` ต่อจาก `</w:compat>` ใน settings.xml
(4) ฟอนต์ TH SarabunPSK ที่ ascii/hAnsi/cs/eastAsia ตั้งทั้ง sz และ szCs และ bCs คู่กับตัวหนา
ไฟล์ที่สร้างด้วยวิธีอื่นให้รัน `python3 scripts/thai_docx_fix.py file.docx` แล้วตรวจด้วย `--check`

**(ค) ท้ายคำตอบ** สรุปสั้น ๆ: ชนิดหนังสือที่ใช้และเหตุผล (๑ บรรทัด) · ช่องที่ยังต้องเติม · ข้อสังเกตที่ผู้ใช้ควรตัดสินใจ (เช่น ธรรมเนียมหน่วยงานที่ต่างจากระเบียบ)

## รายการตรวจก่อนส่ง (ทุกชนิด)

- [ ] ชนิดหนังสือเหมาะกับผู้รับและเรื่อง และมี **ทุกส่วน** ตามแบบ (ส่วน "(ถ้ามี)" ใส่เมื่อมีจริงเท่านั้น)
- [ ] คำขึ้นต้นตรงฐานะผู้รับ และ **เข้าคู่** กับคำลงท้าย; หลังคำขึ้นต้นเป็นตำแหน่งผู้รับ
- [ ] วันที่ = เลขวันที่ + ชื่อเต็มของเดือน + ปี พ.ศ.; คำสั่ง/ระเบียบ/ประกาศ/หนังสือรับรองมี "พ.ศ." ในบรรทัด "… ณ วันที่"
- [ ] เลขที่: `รหัสพยัญชนะ เลขประจำ/เลขทะเบียนส่ง` (หนังสือเวียนเติม `ว`) · คำสั่ง/หนังสือรับรอง `ลำดับ/พ.ศ.`
- [ ] "อ้างถึง" ใช้กับหนังสือที่ผู้รับเคยได้รับแล้ว · "สิ่งที่ส่งมาด้วย" ใช้กับสิ่งที่แนบไปครั้งนี้ · ทั้งสองถูกกล่าวถึงในเนื้อความ
- [ ] ย่อหน้าสุดท้ายบอกความประสงค์ชัด ("จึงเรียนมาเพื่อ…") · ขึ้นต้น "ตามที่" แล้วปิดด้วย "นั้น"
- [ ] ไม่มีภาษาพูด คำย่อที่ไม่จำเป็น ตัวเลขไทย/อารบิกปนกัน
- [ ] ชื่อผู้ลงนามมีคำนำนามเต็ม · ลงชื่อแทนใช้คำถูกและต่อด้วยตำแหน่งเจ้าของหนังสือ
- [ ] ไม่มีข้อมูลที่แต่งขึ้นเองหรือเติมจากความจำ — ข้อมูลที่ไม่มีเป็น `[…]` และแจ้งผู้ใช้แล้ว
- [ ] หนังสือเวียน: เลขที่มี `ว` · หนังสือถึงพระสงฆ์: คำลงท้ายตรงชั้นสมณศักดิ์ ใช้ อาราธนา/นิมนต์/ถวาย/ปัจจัย
- [ ] ไฟล์ .docx ผ่าน `thai_docx_fix.py --check` (กฎภาษาไทยของ Word ครบ ๔ ข้อ)

## หลักการตีความ

- ระเบียบเป็นมาตรฐานกลาง แต่ข้อ ๑๒ วรรคท้ายเปิดให้กระทรวง/กรม/จังหวัดกำหนดแบบหนังสือภายในเองได้ และหนังสือสั่งการ/ประชาสัมพันธ์
  ที่มีกฎหมายกำหนดแบบไว้โดยเฉพาะให้ใช้แบบตามกฎหมายนั้น (ข้อ ๑๕, ๑๙) — ถ้าผู้ใช้มีแบบของหน่วยงาน ให้ยึดแบบของหน่วยงาน
- ค่าที่ระเบียบกำหนด (ครุฑ ๓/๑.๕ ซม., A4, ชั้นความเร็วสีแดง ≥ ๓๒ pt) ต้องตรง; ระยะขอบ ฟอนต์ ย่อหน้า เป็นแนวปฏิบัติ (`references/layout-spec.md`)
- ค่าเริ่มต้นของสกิล: ฟอนต์ **TH SarabunPSK** (ทางเลือก TH Sarabun New) ขนาด ๑๖ pt และ **เลขไทย** ทั้งฉบับ — ไม่ใช้ TH SarabunIT๙
  เว้นแต่ผู้ใช้ขอ (ใช้ `--font` / `--arabic-digits` ตามที่ผู้ใช้ระบุ)
- รายการรหัสกระทรวงในภาคผนวก ๑ เป็นโครงสร้างเก่า — รหัสกระทรวงใหม่ใน `references/numbering-and-codes.md` ระบุไว้ว่าเป็นรหัสตามทางปฏิบัติ ให้ผู้ใช้ยืนยัน
- เมื่อต้องการอ้างตัวบทให้แม่นยำ ค้นใน `references/source/` (เช่น `grep -n "ข้อ ๒๘" references/source/regulation-text.md`)
