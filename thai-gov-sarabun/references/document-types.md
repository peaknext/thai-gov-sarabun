# ชนิดของหนังสือราชการ และวิธีเลือกให้ถูกชนิด

ที่มา: ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖ (แก้ไขถึงฉบับที่ ๔ พ.ศ. ๒๕๖๔) หมวด ๑ ข้อ ๙–๓๔
ข้อความเต็มดูได้ที่ `source/regulation-text.md`

## หนังสือราชการคืออะไร (ข้อ ๙)

เอกสารที่เป็นหลักฐานในราชการ ได้แก่ (๙.๑) หนังสือระหว่างส่วนราชการ (๙.๒) หนังสือที่ส่วนราชการมีไปถึงหน่วยงานอื่นซึ่งมิใช่ส่วนราชการหรือบุคคลภายนอก
(๙.๓) หนังสือที่หน่วยงานอื่น/บุคคลภายนอกมีมาถึงส่วนราชการ (๙.๔) เอกสารที่ทางราชการจัดทำขึ้นเพื่อเป็นหลักฐานในราชการ
(๙.๕) เอกสารที่ทางราชการจัดทำขึ้นตามกฎหมาย ระเบียบ หรือข้อบังคับ (๙.๖) ข้อมูลข่าวสารหรือหนังสือที่ได้รับจากระบบสารบรรณอิเล็กทรอนิกส์

## ตัวช่วยตัดสินใจ — ผู้ใช้ต้องการอะไร → ใช้แบบไหน

| สถานการณ์ | ใช้ |
|---|---|
| ติดต่อ **ต่างกระทรวง/ต่างกรมที่ไม่อยู่ในกระทรวงเดียวกัน** / ถึงเอกชน บริษัท ประชาชน / เรื่องเป็นทางการ (เชิญ ขอความร่วมมือ แจ้ง ตอบ) | หนังสือภายนอก |
| ติดต่อ **ภายในกระทรวง ทบวง กรม หรือจังหวัดเดียวกัน** (ข้อ ๑๒) | หนังสือภายใน |
| เสนอผู้บังคับบัญชา ขออนุมัติ รายงาน / ผู้บังคับบัญชาสั่งการ / หน่วยงานต่ำกว่ากรมติดต่อกัน (ข้อ ๒๖) | บันทึก (บนกระดาษบันทึกข้อความ) |
| เรื่อง **ไม่สำคัญ** ระดับกรมขึ้นไป: ขอรายละเอียดเพิ่ม ส่งสำเนา/สิ่งของ ตอบรับทราบ แจ้งผลงาน เตือนเรื่องค้าง หรือเรื่องที่หัวหน้าส่วนราชการระดับกรมสั่งให้ใช้ (ข้อ ๑๓) | หนังสือประทับตรา |
| ผู้บังคับบัญชาสั่งการให้ปฏิบัติโดยชอบด้วยกฎหมาย เช่น แต่งตั้งคณะกรรมการ มอบหมายงาน ย้าย (ข้อ ๑๖) | คำสั่ง |
| วางหลักปฏิบัติงานเป็นการประจำ (อาจอาศัยหรือไม่อาศัยอำนาจกฎหมายก็ได้) (ข้อ ๑๗) | ระเบียบ |
| กำหนดให้ใช้โดย **อาศัยอำนาจกฎหมายที่บัญญัติให้กระทำได้** (ข้อ ๑๘) | ข้อบังคับ |
| ประกาศ/ชี้แจงให้ทราบ หรือแนะแนวทางปฏิบัติ เช่น รับสมัคร ผลการคัดเลือก ประกาศราคา (ข้อ ๒๐) — ถ้ากฎหมายกำหนดให้ทำเป็น "แจ้งความ" ให้เปลี่ยนคำ | ประกาศ |
| แถลงเพื่อทำความเข้าใจในกิจการของทางราชการ หรือเหตุการณ์ใด ๆ (ข้อ ๒๑) เช่น สถานการณ์ภัยพิบัติ | แถลงการณ์ |
| ข้อความที่ทางราชการเห็นสมควรเผยแพร่ให้ทราบ (ข้อ ๒๒) | ข่าว |
| รับรองแก่บุคคล นิติบุคคล หรือหน่วยงาน ให้ปรากฏแก่บุคคลทั่วไป (ข้อ ๒๔) เช่น รับรองการทำงาน เงินเดือน | หนังสือรับรอง |
| บันทึกความคิดเห็นและมติของที่ประชุม (ข้อ ๒๕) | รายงานการประชุม |
| หนังสือมีถึงผู้รับจำนวนมาก ใจความเดียวกัน (ข้อ ๓๒) | หนังสือเวียน (ใช้แบบภายนอก/ภายใน/ประทับตรา แล้วเติม "ว" หน้าเลขทะเบียนส่ง) |

ถ้าคลุมเครือระหว่าง "ภายนอก" กับ "ภายใน": ดูว่าผู้ส่งและผู้รับอยู่ใน **กระทรวง ทบวง กรม หรือจังหวัดเดียวกัน** หรือไม่ ถ้าใช่ → ภายในได้ ถ้าไม่ → ภายนอก

## องค์ประกอบร่วมที่ใช้กับหลายชนิด

### ชั้นความเร็ว (ข้อ ๒๘)
- **ด่วนที่สุด** — ปฏิบัติทันทีที่ได้รับ · **ด่วนมาก** — ปฏิบัติโดยเร็ว · **ด่วน** — ปฏิบัติเร็วกว่าปกติเท่าที่จะทำได้
- พิมพ์ด้วย **ตัวอักษรสีแดง ขนาดไม่เล็กกว่า ๓๒ พอยท์** ให้เห็นชัดบนหนังสือและบนซอง (ใช้กับแบบที่ ๑, ๒, ๓ และซอง แบบที่ ๑๕)
- ต้องการให้ถึงภายในเวลา: ระบุ "ด่วนภายใน" แล้วลงวัน เดือน ปี และเวลา เช่น "ด่วนภายใน ๒๕ พฤศจิกายน ๒๕๖๙ เวลา ๑๒.๐๐ น."
- ใส่ชั้นความเร็วเฉพาะเมื่อเรื่องจำเป็นจริง (มีกำหนดเวลา) — อย่าใส่โดยอัตโนมัติ

### ชั้นความลับ (ลับ / ลับมาก / ลับที่สุด)
- แบบที่ ๑–๓ มีตำแหน่ง "ชั้นความลับ (ถ้ามี)" ที่กึ่งกลางทั้งด้านบนและด้านล่างของหน้า
- วิธีกำหนดและปฏิบัติเป็นไปตามระเบียบว่าด้วยการรักษาความลับของทางราชการ (ข้อ ๕) — ชั้นลับที่สุดห้ามส่งทางระบบสารบรรณอิเล็กทรอนิกส์ (ข้อ ๒๙)

### การติดต่อด้วยระบบอิเล็กทรอนิกส์ (ข้อ ๒๙, ๒๙/๑, หมวด ๕)
- ให้ติดต่อราชการด้วยระบบสารบรรณอิเล็กทรอนิกส์เป็นหลัก เว้นแต่ข้อมูลลับที่สุดหรือมีเหตุจำเป็น
- ผู้ส่งตรวจสอบผลการส่งทุกครั้ง ผู้รับแจ้งตอบรับ เมื่อได้ตอบรับแล้วไม่ต้องส่งเอกสารตามไปอีก

### สำเนาคู่ฉบับ (ข้อ ๓๐)
- เก็บไว้ที่ต้นเรื่อง ๑ ฉบับ และที่หน่วยงานสารบรรณกลาง ๑ ฉบับ
- ผู้ลงชื่อลงลายมือชื่อหรือลายมือชื่อย่อ และ **ผู้ร่าง ผู้พิมพ์ ผู้ตรวจ** ลงลายมือชื่อหรือลายมือชื่อย่อไว้ที่ข้างท้ายขอบล่างด้านขวาของหนังสือ
  (ใน docx ให้เว้นที่ไว้ หรือพิมพ์ "ร่าง/พิมพ์/ตรวจ ......" เล็ก ๆ ที่มุมขวาล่างเฉพาะในสำเนาคู่ฉบับ ถ้าผู้ใช้ขอ)

### สำเนาหนังสือส่งให้ส่วนราชการอื่นทราบ (ข้อ ๓๑)
- โดยปกติส่งเป็น **หนังสือประทับตรา**
- สำเนาต้องมีคำรับรอง "สำเนาถูกต้อง" ลงลายมือชื่อรับรอง ชื่อตัวบรรจง ตำแหน่ง และวัน เดือน ปีที่รับรอง ไว้ที่ขอบล่าง
  ผู้รับรอง: ข้าราชการพลเรือน/พนักงานส่วนท้องถิ่น ประเภทวิชาการ ระดับปฏิบัติการ หรือประเภททั่วไป ระดับชำนาญงานขึ้นไป หรือเจ้าหน้าที่ของรัฐอื่นที่เทียบเท่า หรือพนักงานราชการ ซึ่งเป็นเจ้าของเรื่อง

### หนังสือเวียน (ข้อ ๓๒)
- เติมรหัสตัวพยัญชนะ **ว** หน้าเลขทะเบียนหนังสือส่ง เช่น "ที่ นร ๐๑๐๖/ว ๙๑๓" (เลขเวียนเฉพาะ เริ่ม ๑ ทุกปีปฏิทิน หรือใช้เลขทั่วไปก็ได้)

### หนังสือภาษาต่างประเทศ (ข้อ ๓๔)
- ใช้กระดาษตราครุฑ · ภาษาอังกฤษทำตามภาคผนวก ๔ (`english-letters.md`) · ภาษาอื่นตามประเพณีนิยม

## รูปแบบตัวเลข วันที่ และเลขที่ (ใช้ทุกชนิด)

- วันที่: **ตัวเลขวันที่ + ชื่อเต็มของเดือน + ตัวเลขปีพุทธศักราช** เช่น "๒๑ พฤศจิกายน ๒๕๖๙" (ข้อ ๑๑.๓ ฯลฯ) — ห้ามใช้เดือนย่อหรือ ค.ศ. ในหัวหนังสือ
- คำสั่ง/ระเบียบ/ข้อบังคับ/ประกาศ/หนังสือรับรอง: ท้ายเรื่องใช้ "สั่ง ณ วันที่ / ประกาศ ณ วันที่ / ให้ไว้ ณ วันที่ ๒๑ พฤศจิกายน พ.ศ. ๒๕๖๙" (แบบฟอร์มพิมพ์ "พ.ศ." ไว้)
- เลขที่คำสั่ง: เลขลำดับ / ปี พ.ศ. เช่น "ที่ ๑๒๕/๒๕๖๙" (ข้อ ๑๖.๒) — หนังสือรับรองใช้รูปแบบเดียวกัน หรือใช้เลขหนังสือทั่วไป (ข้อ ๒๔.๑)
- เลขที่หนังสือภายนอก/ภายใน/ประทับตรา: รหัสพยัญชนะ + เลขประจำเจ้าของเรื่อง / เลขทะเบียนหนังสือส่ง เช่น "ที่ ศธ ๐๒๐๑/๑๒๓" (ภาคผนวก ๑, ดู `numbering-and-codes.md`)
- เอกสารราชการนิยมใช้ **เลขไทย** ทั้งฉบับ (ยกเว้นอีเมล URL ชื่อไฟล์ และข้อความภาษาอังกฤษ) — ถ้าหน่วยงานผู้ใช้ใช้เลขอารบิก ให้ใช้ตามนั้นอย่างสม่ำเสมอทั้งฉบับ
