# คำขึ้นต้น สรรพนาม คำลงท้าย และคำจ่าหน้าซอง (ภาคผนวก ๒)

ที่มา: ภาคผนวก ๒ ท้ายระเบียบฯ (PDF หน้า 69–71) ซึ่งข้อ ๓.๑ ถูกแก้ไขโดยหนังสือสำนักนายกรัฐมนตรี
ที่ นร ๐๑๐๖/ว ๙๑๓ ลงวันที่ ๘ พฤษภาคม ๒๕๕๕ (PDF หน้า 72–73) — ตารางด้านล่างคือฉบับที่แก้ไขแล้ว
ข้อความดิบจากต้นฉบับอยู่ที่ `source/annex-2-salutations.md`

ระเบียบอ้างถึงตารางนี้ใน ข้อ ๑๑.๕ / ๑๑.๙ (หนังสือภายนอก), ข้อ ๑๒.๕ (หนังสือภายใน), ข้อ ๒๖.๑ (บันทึก),
ข้อ ๓๓ (สรรพนาม) และภาคผนวก ๗ ข้อ ๕.๓.๖ (อีเมล)

## วิธีเลือกใช้ (สรุปสั้น)

1. ดูว่า **ผู้รับ** อยู่กลุ่มใด: พระราชวงศ์ (๑) / พระภิกษุ (๒) / บุคคลธรรมดา (๓)
2. บุคคลธรรมดา: ถ้าผู้รับเป็นตำแหน่งในรายการ ๓.๑ (๑๕ ตำแหน่ง) ใช้ **กราบเรียน … ขอแสดงความนับถืออย่างยิ่ง**
   นอกนั้นทั้งหมด (อธิบดี ผู้ว่าราชการจังหวัด รัฐมนตรี ปลัดกระทรวง ประชาชน บริษัท ฯลฯ) ใช้ **เรียน … ขอแสดงความนับถือ**
3. หมายเหตุ (๓): เมื่อมีหนังสือถึง "ตำแหน่ง" ให้ใช้คำตามตำแหน่ง ไม่ใช่ตามตัวบุคคล
4. หลังคำขึ้นต้น ให้ลง **ตำแหน่ง** ของผู้รับ (เช่น "เรียน ผู้ว่าราชการจังหวัดขอนแก่น") หรือชื่อบุคคลเมื่อมีถึงตัวบุคคลไม่เกี่ยวกับตำแหน่ง (ข้อ ๑๑.๕)
5. คำขึ้นต้นกับคำลงท้ายต้อง **เข้าคู่กัน** เสมอ — "กราบเรียน" คู่กับ "ขอแสดงความนับถืออย่างยิ่ง", "เรียน" คู่กับ "ขอแสดงความนับถือ"
6. หนังสือภายใน/บันทึกข้อความ ใช้คำขึ้นต้นตามตารางนี้ แต่ **ไม่มีคำลงท้าย** (แบบที่ ๒)

> ข้อควรระวังที่พบบ่อย: รัฐมนตรีว่าการกระทรวง ปลัดกระทรวง ผู้ว่าราชการจังหวัด **ไม่อยู่** ในรายการ ๓.๑
> ดังนั้นตามระเบียบใช้ "เรียน" (บางหน่วยงานใช้ "กราบเรียน" ตามธรรมเนียมภายใน — ให้ถามผู้ใช้ถ้าเขาระบุธรรมเนียมของหน่วยงาน
> มิฉะนั้นให้ยึดระเบียบ)

## หมายเหตุท้ายตาราง (ตามต้นฉบับ)

(๑) ผู้ที่เชิญกระแสพระบรมราชโองการไปยังผู้ใด ไม่ต้องใช้คำลงท้ายในหนังสือนั้น
(๒) คำที่ใช้ในหนังสือถึงพระราชวงศ์ และพระภิกษุ ตาม ๑ และ ๒ ให้ใช้คำราชาศัพท์ หรือถ้อยคำสุภาพ ซึ่งเป็นไปตามขนบธรรมเนียม ประเพณี หรือตามที่ทางราชการกำหนด
(๓) ในกรณีที่มีหนังสือถึงผู้รับระบุเฉพาะตำแหน่ง ให้ใช้คำขึ้นต้น สรรพนาม คำลงท้ายในหนังสือราชการและคำที่ใช้ในการจ่าหน้าซอง ตามตำแหน่ง

## การใช้สรรพนามในเนื้อความ (ข้อ ๓๓ — ตามฐานะความสัมพันธ์)

- หนังสือในนามส่วนราชการ: เรียกตนเองด้วย **ชื่อส่วนราชการ** (เช่น "กรมควบคุมโรคขอเรียนว่า…") และเรียกผู้รับด้วย **ตำแหน่ง/ชื่อส่วนราชการ** หรือ "ท่าน" — เป็นวิธีที่ใช้แพร่หลายที่สุดและปลอดภัยที่สุด
- หนังสือในนามบุคคล (เช่น บันทึกเสนอผู้บังคับบัญชา): ใช้ "ข้าพเจ้า" (กลาง) / "กระผม" "ผม" (ชาย) / "ดิฉัน" (หญิง) ตามตาราง
- พระภิกษุและพระราชวงศ์ ต้องใช้สรรพนามตามตารางข้างต้นเท่านั้น และใช้ราชาศัพท์/คำสุภาพตลอดเนื้อความ

## ถ้าไม่แน่ใจ

- ผู้รับเป็นหน่วยงาน (ไม่ใช่ตำแหน่ง) เช่น บริษัท มูลนิธิ → "เรียน ผู้จัดการบริษัท…" / "เรียน ประธานมูลนิธิ…" (ระบุตำแหน่งหัวหน้าหน่วยงาน)
- ผู้รับเป็นประชาชนทั่วไป → "เรียน นายสมชาย ใจดี" (ชื่อบุคคล) … "ขอแสดงความนับถือ"
- หนังสือเวียนถึงผู้รับหลายราย → "เรียน หัวหน้าส่วนราชการระดับกรม" / "เรียน ผู้ว่าราชการจังหวัด ทุกจังหวัด"
- จดหมายถึงพระราชวงศ์หรือพระภิกษุชั้นสูง: แนะนำให้ผู้ใช้ตรวจสอบราชาศัพท์และพระนามกับสำนักพระราชวัง/สำนักราชเลขาธิการ หรือสำนักงานพระพุทธศาสนาแห่งชาติ ก่อนส่ง
