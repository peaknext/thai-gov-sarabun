# หนังสือภายใน และ บันทึก (แบบที่ ๒ / แบบที่ ๒๙ · ระเบียบข้อ ๑๒, ๒๖, ๗๖)

- **หนังสือภายใน** (ข้อ ๑๒): หนังสือติดต่อราชการที่เป็นแบบพิธีน้อยกว่าหนังสือภายนอก ใช้ติดต่อ **ภายในกระทรวง ทบวง กรม หรือจังหวัดเดียวกัน** ใช้กระดาษบันทึกข้อความ
- **บันทึก** (ข้อ ๒๖): ข้อความที่ผู้ใต้บังคับบัญชาเสนอต่อผู้บังคับบัญชา หรือผู้บังคับบัญชาสั่งการแก่ผู้ใต้บังคับบัญชา หรือที่เจ้าหน้าที่/หน่วยงานต่ำกว่ากรมติดต่อกันในการปฏิบัติราชการ — โดยปกติใช้กระดาษบันทึกข้อความเช่นกัน
- **กระดาษบันทึกข้อความ** (ข้อ ๗๖, แบบที่ ๒๙): ขนาด A4 หรือ A5 พิมพ์ครุฑสูง ๑.๕ ซม. ด้วยหมึกสีดำที่มุมบนด้านซ้าย

## โครงร่างตามแบบที่ ๒

```text
                              ชั้นความลับ (ถ้ามี)
[ครุฑ ๑.๕ ซม.] ชั้นความเร็ว (ถ้ามี)      บันทึกข้อความ
ส่วนราชการ ....................................................................
ที่ ....................................... วันที่ ...............................
เรื่อง ........................................................................
(คำขึ้นต้น)
                (ข้อความ) ...................................................
.............................................................................

                                   (ลงชื่อ)
                                          (พิมพ์ชื่อเต็ม)
                                            (ตำแหน่ง)
                              ชั้นความลับ (ถ้ามี)
```

ข้อสังเกตจากแบบ: "บันทึกข้อความ" ตัวหนาขนาดใหญ่กึ่งกลาง · หัวข้อ "ส่วนราชการ / ที่ / วันที่ / เรื่อง" ตัวหนา ·
**ไม่มีคำลงท้าย** และ **ไม่มีบล็อกส่วนราชการเจ้าของเรื่อง/โทร.** ท้ายหนังสือ (หมายเลขโทรศัพท์ใส่ในบรรทัด "ส่วนราชการ")

## วิธีกรอกแต่ละส่วน (ข้อ ๑๒.๑–๑๒.๗)

| ส่วน | วิธีกรอก |
|---|---|
| ส่วนราชการ | ชื่อส่วนราชการเจ้าของเรื่องหรือหน่วยงานที่ออกหนังสือ โดยมีรายละเอียดพอสมควร — ถ้าผู้ออกอยู่ระดับกรมขึ้นไป ลงทั้งระดับกรมและกอง; ถ้าต่ำกว่ากรม ลงเพียงระดับกอง หรือส่วนราชการเจ้าของเรื่อง **พร้อมหมายเลขโทรศัพท์ (ถ้ามี)** — `กองคลัง สำนักงานปลัดกระทรวงสาธารณสุข โทร. ๐ ๒๕๙๐ ๑๕๐๐` |
| ที่ | รหัสพยัญชนะและเลขประจำของเจ้าของเรื่อง ทับเลขทะเบียนหนังสือส่ง (เหมือนหนังสือภายนอก) — `สธ ๐๒๐๖/๒๔๕` |
| วันที่ | ตัวเลขวันที่ ชื่อเต็มของเดือน ตัวเลขปี พ.ศ. |
| เรื่อง | เรื่องย่อที่เป็นใจความสั้นที่สุด |
| คำขึ้นต้น | ตามภาคผนวก ๒ แล้วลงตำแหน่งผู้รับ — `เรียน ผู้อำนวยการกองคลัง` |
| ข้อความ | สาระสำคัญชัดเจนเข้าใจง่าย แยกเป็นข้อ ๆ ได้ — **ถ้ามีการอ้างถึงหนังสือหรือมีสิ่งที่ส่งมาด้วย ให้ระบุไว้ในข้อความ** (ไม่มีหัวข้อ "อ้างถึง/สิ่งที่ส่งมาด้วย" แยก) |
| ลงชื่อและตำแหน่ง | ปฏิบัติตามข้อ ๑๑.๑๐ และ ๑๑.๑๑ โดยอนุโลม |

กระทรวง ทบวง กรม หรือจังหวัดใดจะกำหนดแบบการเขียนโดยเฉพาะก็ได้ (ข้อ ๑๒ วรรคท้าย) — ถ้าผู้ใช้ให้แบบของหน่วยงานมา ให้ยึดแบบนั้น

## บันทึก (ข้อ ๒๖) — หัวข้อที่ต้องมี

๒๖.๑ ชื่อหรือตำแหน่งที่บันทึกถึง (ใช้คำขึ้นต้นตามภาคผนวก ๒) · ๒๖.๒ สาระสำคัญของเรื่อง (ถ้ามีเอกสารประกอบให้ระบุ) ·
๒๖.๓ ลายมือชื่อและตำแหน่งผู้บันทึก — ถ้าไม่ใช้กระดาษบันทึกข้อความ ให้ลงวัน เดือน ปีที่บันทึกไว้ด้วย

**บันทึกต่อเนื่อง** (เกษียนหนังสือ): ผู้บันทึกระบุคำขึ้นต้น ใจความบันทึก และลงชื่อ แล้วลงวัน เดือน ปี กำกับใต้ลายมือชื่อ
หากไม่มีความเห็นเพิ่มเติมให้ลงชื่อและวัน เดือน ปีกำกับเท่านั้น ตัวอย่าง:

```text
เรียน  อธิบดี
     เพื่อโปรดพิจารณาอนุมัติตามเสนอ
                     (ลงชื่อ) .................
                     (นายวิชัย แก้วมณี)
                     ผู้อำนวยการกองคลัง
                     ๒๑ พ.ย. ๒๕๖๙
```

บันทึกที่จัดทำในระบบสารบรรณอิเล็กทรอนิกส์ อีเมล หรือระบบสื่อสารที่มีการยืนยันตัวตน **พิมพ์ชื่อผู้บันทึกแทนลายมือชื่อได้**
และไม่ต้องลงวันที่ถ้าระบบบันทึกวันที่ไว้แล้ว (ข้อ ๒๖ วรรคสาม — ฉบับที่ ๔ พ.ศ. ๒๕๖๔)

## โครงข้อความที่ใช้บ่อยในบันทึกเสนอ

```text
เรียน  (ตำแหน่งผู้บังคับบัญชา)
          ๑. เรื่องเดิม / ความเป็นมา ……………………………
          ๒. ข้อเท็จจริง ……………………………
          ๓. ข้อกฎหมาย / ระเบียบที่เกี่ยวข้อง (ถ้ามี) ……………………………
          ๔. ข้อพิจารณา / ความเห็น ……………………………
          ๕. ข้อเสนอ ……………………………
          จึงเรียนมาเพื่อโปรดพิจารณา (หาก/ถ้าเห็นชอบ โปรดลงนามในหนังสือที่เสนอมาพร้อมนี้)
```

## จุดตรวจเฉพาะ

- ผู้ส่งและผู้รับอยู่ในกระทรวง ทบวง กรม หรือจังหวัดเดียวกันจริงหรือไม่ — ถ้าไม่ใช่ต้องเป็นหนังสือภายนอก
- ไม่มีคำลงท้าย ("ขอแสดงความนับถือ") ในบันทึกข้อความ
- เบอร์โทรอยู่ในบรรทัด "ส่วนราชการ" ไม่ใช่ท้ายหนังสือ
