# หนังสือถึงพระสงฆ์

ใช้แบบ **หนังสือภายนอก (แบบที่ ๑)** ตามปกติ แต่คำขึ้นต้น สรรพนาม คำลงท้าย และถ้อยคำในเนื้อความต้องเป็นไปตาม
ภาคผนวก ๒ ข้อ ๒ (พระภิกษุ) และหมายเหตุ (๒): "ให้ใช้คำราชาศัพท์ หรือถ้อยคำสุภาพ ซึ่งเป็นไปตามขนบธรรมเนียม ประเพณี หรือตามที่ทางราชการกำหนด"
(ตารางเต็มใน `../salutations.md` · ต้นฉบับ `../source/annex-2-salutations.md`)

## เลือกระดับตามสมณศักดิ์ของพระผู้รับ

| พระผู้รับ | คำขึ้นต้น | เรียกพระผู้รับ | เรียกตนเอง (ถ้าเขียนในนามบุคคล) | คำลงท้าย | จ่าหน้าซอง |
|---|---|---|---|---|---|
| สมเด็จพระสังฆราชเจ้า (ที่ทรงเป็นเจ้านาย — แถว ๒.๑) | ขอประทานกราบทูล (ออกพระนาม) | ใต้ฝ่าพระบาท | ข้าพระพุทธเจ้า | ควรมิควรแล้วแต่จะโปรดเกล้าโปรดกระหม่อม | ขอประทานกราบทูล (ระบุพระนาม) |
| สมเด็จพระสังฆราช (แถว ๒.๒) | กราบทูล | ฝ่าพระบาท | เกล้ากระหม่อม (ชาย) / เกล้ากระหม่อมฉัน (หญิง) | ควรมิควรแล้วแต่จะโปรด | กราบทูล (ระบุพระนาม) |
| **สมเด็จพระราชาคณะ / รองสมเด็จพระราชาคณะ** (สมเด็จพระ… , พระราชาคณะชั้นรองสมเด็จ เช่น พระพรหม…) | นมัสการ | **พระคุณเจ้า** | กระผม / ดิฉัน | **ขอนมัสการด้วยความเคารพอย่างยิ่ง** | นมัสการ |
| **พระราชาคณะ** (ชั้นธรรม พระธรรม… · ชั้นเทพ พระเทพ… · ชั้นราช พระราช… · ชั้นสามัญ พระ+ราชทินนาม — เรียกกันว่า "เจ้าคุณ") | นมัสการ | **พระคุณท่าน** | กระผม / ดิฉัน | **ขอนมัสการด้วยความเคารพอย่างสูง** | นมัสการ |
| **พระภิกษุสงฆ์ทั่วไป** (รวมพระครูสัญญาบัตร พระครูฐานานุกรม พระมหา พระใบฎีกา เจ้าอาวาสทั่วไป) | นมัสการ | **ท่าน** | ผม / ดิฉัน | **ขอนมัสการด้วยความเคารพ** | นมัสการ |

- หนังสือถึงสมเด็จพระสังฆราช ควรให้ผู้ใช้ตรวจสอบพระนามและราชาศัพท์ที่ใช้ในปัจจุบันกับสำนักพระราชวัง/สำนักงานพระพุทธศาสนาแห่งชาติก่อนส่ง
- ถ้าไม่ทราบสมณศักดิ์ ให้ถามผู้ใช้หรือเว้น `[สมณศักดิ์/ราชทินนาม]` — **อย่าเดา** เพราะคำลงท้ายต่างกันตามชั้น
- หนังสือในนามส่วนราชการ (กรณีปกติ) เรียกตนเองด้วย **ชื่อส่วนราชการ** ("สำนักงานเขต…ขอนมัสการเรียนว่า…") ไม่ต้องใช้ กระผม/ดิฉัน
- หลังคำขึ้นต้น ให้ลง **สมณศักดิ์/ชื่อพระ + ตำแหน่ง** เช่น `นมัสการ พระราชสุทธิธรรมเมธี เจ้าอาวาสวัดศรีสุพรรณาราม`
  · พระทั่วไป: `นมัสการ พระครูสุนทรธรรมโกวิท เจ้าอาวาสวัดหนองบัว` · ไม่ทราบสมณศักดิ์แต่ทราบตำแหน่ง: `นมัสการ เจ้าอาวาสวัดหนองบัว`
- ชื่อพระที่ไม่มีสมณศักดิ์: พระ + ชื่อ + ฉายา (ไม่ใส่นามสกุล) เช่น `พระสมชาย ฐิตธมฺโม`

## ถ้อยคำที่ใช้กับพระสงฆ์ (คำสุภาพ/คำราชาศัพท์สำหรับพระ)

| คำทั่วไป | ใช้กับพระสงฆ์ |
|---|---|
| เชิญ (ให้มาประกอบพิธี เทศน์ สวด) | **อาราธนา** (พิธีกรรม: อาราธนาเจริญพระพุทธมนต์ อาราธนาแสดงพระธรรมเทศนา) |
| เชิญ (ให้มาฉันภัตตาหาร / มาร่วมงาน) | **นิมนต์** (นิมนต์ฉันภัตตาหารเพล) |
| ให้, มอบ | **ถวาย** (ถวายภัตตาหาร ถวายปัจจัย ถวายผ้าไตร) |
| เงิน | **ปัจจัย** |
| กิน / อาหาร | **ฉัน** / **ภัตตาหาร** (เช้า: ภัตตาหารเช้า; เพล: ภัตตาหารเพล) |
| นอน / ที่พัก | **จำวัด** / **กุฏิ** |
| อาบน้ำ | สรงน้ำ |
| ป่วย | อาพาธ |
| ตาย | มรณภาพ (สมเด็จพระราชาคณะ: ถึงแก่มรณภาพ; สมเด็จพระสังฆราช: สิ้นพระชนม์) |
| สวดมนต์ | เจริญพระพุทธมนต์ |
| เทศน์ | แสดงพระธรรมเทศนา |
| ขอบคุณ | ขอนมัสการขอบพระคุณ / ขอกราบขอบพระคุณ |
| อนุญาต | อนุญาต (ใช้ได้) / ขอความเมตตา… |
| ขอความช่วยเหลือ | ขอความเมตตาอนุเคราะห์ |

ประโยคปิดท้ายที่นิยม: "จึงนมัสการมาเพื่อโปรดพิจารณาให้ความเมตตาอนุเคราะห์" · "จึงนมัสการมาเพื่อโปรดทราบ" ·
"จึงนมัสการมาเพื่อโปรดพิจารณารับอาราธนา และขอนมัสการขอบพระคุณมา ณ โอกาสนี้"

## ตัวอย่าง: อาราธนาพระสงฆ์เจริญพระพุทธมนต์ (ถึงพระราชาคณะ — ชื่อพระและวัดในตัวอย่างเป็นชื่อสมมุติ)

```text
                                   [ครุฑ]
ที่ ชม ๐๐๑๗/                                            ศาลากลางจังหวัดเชียงใหม่
                                                        ถนนโชตนา ชม ๕๐๓๐๐
                                    ๒๑ พฤศจิกายน ๒๕๖๙
เรื่อง  อาราธนาพระสงฆ์เจริญพระพุทธมนต์
นมัสการ  พระราชสุทธิธรรมเมธี เจ้าอาวาสวัดศรีสุพรรณาราม
สิ่งที่ส่งมาด้วย  กำหนดการ จำนวน ๑ ชุด

          ด้วยจังหวัดเชียงใหม่กำหนดจัดพิธีทำบุญตักบาตรเนื่องในวันขึ้นปีใหม่ พุทธศักราช ๒๕๗๐
ในวันศุกร์ที่ ๑ มกราคม ๒๕๗๐ เวลา ๐๗.๐๐ น. ณ ข่วงประตูท่าแพ อำเภอเมืองเชียงใหม่
          ในการนี้ จังหวัดเชียงใหม่ใคร่ขออาราธนาพระคุณท่านพร้อมด้วยพระสงฆ์ จำนวน ๙ รูป
เจริญพระพุทธมนต์ในพิธีดังกล่าว รายละเอียดปรากฏตามสิ่งที่ส่งมาด้วย
          จึงนมัสการมาเพื่อโปรดพิจารณารับอาราธนา และขอนมัสการขอบพระคุณมา ณ โอกาสนี้

                              ขอนมัสการด้วยความเคารพอย่างสูง

                                   (นาย……………………)
                                   ผู้ว่าราชการจังหวัดเชียงใหม่
สำนักงานจังหวัด
โทร. ……………
```

## จุดตรวจเฉพาะ

- คำลงท้ายตรงกับชั้นของพระผู้รับ (อย่างยิ่ง / อย่างสูง / ด้วยความเคารพ) — check_draft.py ตรวจจากคำนำหน้าสมณศักดิ์ให้คร่าว ๆ
- ใช้ "อาราธนา/นิมนต์/ถวาย/ปัจจัย/ฉัน" ไม่ใช้ "เชิญ/ให้/เงิน/รับประทาน"
- ลักษณนามของพระคือ **รูป** (พระสงฆ์ ๙ รูป) ไม่ใช่ "คน/องค์" (เว้นพระพุทธรูปใช้ "องค์")
- ปีในพิธีทางศาสนานิยมเขียน "พุทธศักราช" เต็ม
