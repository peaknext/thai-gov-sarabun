# หนังสือประทับตรา (แบบที่ ๓ · ระเบียบข้อ ๑๓–๑๔)

หนังสือที่ใช้ **ประทับตราแทนการลงชื่อ** ของหัวหน้าส่วนราชการระดับกรมขึ้นไป โดยหัวหน้าส่วนราชการระดับกอง หรือผู้ที่ได้รับมอบหมาย
เป็นผู้รับผิดชอบลงชื่อย่อกำกับตรา ใช้ได้ทั้งระหว่างส่วนราชการกับส่วนราชการ และส่วนราชการกับบุคคลภายนอก
**เฉพาะกรณีที่ไม่ใช่เรื่องสำคัญ** ได้แก่

๑๓.๑ การขอรายละเอียดเพิ่มเติม · ๑๓.๒ การส่งสำเนาหนังสือ สิ่งของ เอกสาร หรือบรรณสาร · ๑๓.๓ การตอบรับทราบที่ไม่เกี่ยวกับราชการสำคัญหรือการเงิน ·
๑๓.๔ การแจ้งผลงานที่ได้ดำเนินการไปแล้วให้ส่วนราชการที่เกี่ยวข้องทราบ · ๑๓.๕ การเตือนเรื่องที่ค้าง ·
๑๓.๖ เรื่องซึ่งหัวหน้าส่วนราชการระดับกรมขึ้นไปกำหนดโดยทำเป็นคำสั่งให้ใช้หนังสือประทับตรา

ถ้าเรื่องเกี่ยวกับการเงิน การอนุมัติ การผูกพัน หรือเป็นเรื่องสำคัญ → ใช้หนังสือภายนอกแทน

## โครงร่างตามแบบที่ ๓

```text
                              ชั้นความลับ (ถ้ามี)
                                   [ครุฑ ๓ ซม.]
ชั้นความเร็ว (ถ้ามี)
ที่ ..........................
ถึง .........................

                (ข้อความ) ...................................................
.............................................................................

                                  (ชื่อส่วนราชการที่ส่งหนังสือออก)
                                       (ตราชื่อส่วนราชการ)
                                          (วัน เดือน ปี)
                                                 (ลงชื่อย่อกำกับตรา)
(ส่วนราชการเจ้าของเรื่อง)
(โทร. หรือที่ตั้ง)
                              ชั้นความลับ (ถ้ามี)
```

**ไม่มี** เรื่อง คำขึ้นต้น คำลงท้าย และลายมือชื่อเต็ม

## วิธีกรอก (ข้อ ๑๔.๑–๑๔.๘)

| ส่วน | วิธีกรอก |
|---|---|
| ที่ | รหัสพยัญชนะและเลขประจำของเจ้าของเรื่อง ทับเลขทะเบียนหนังสือส่ง |
| ถึง | ชื่อส่วนราชการ หน่วยงาน หรือบุคคลที่หนังสือนั้นมีถึง (ไม่ใช้คำขึ้นต้น) |
| ข้อความ | สาระสำคัญชัดเจนเข้าใจง่าย — นิยมขึ้นต้น "ด้วย/ตามที่…" และจบด้วยวัตถุประสงค์ เช่น "…มาเพื่อทราบ" "…มาเพื่อโปรดทราบ" "…มาเพื่อดำเนินการต่อไป" (ไม่ใช้ "จึงเรียนมา" เพราะไม่มีคำขึ้นต้น) |
| ชื่อส่วนราชการที่ส่งหนังสือออก | ชื่อส่วนราชการระดับกรมขึ้นไปที่ส่งหนังสือ |
| ตราชื่อส่วนราชการ | ประทับตราชื่อส่วนราชการ (ข้อ ๗๒) **ด้วยหมึกแดง** และผู้รับผิดชอบลงลายมือชื่อย่อกำกับตรา — ในไฟล์ร่างให้เว้นที่ว่างไว้ |
| วัน เดือน ปี | ตัวเลขวันที่ ชื่อเต็มของเดือน ตัวเลขปี พ.ศ. |
| ส่วนราชการเจ้าของเรื่อง | ชื่อส่วนราชการเจ้าของเรื่องหรือหน่วยงานที่ออกหนังสือ |
| โทร. หรือที่ตั้ง | หมายเลขโทรศัพท์และหมายเลขภายใน (ถ้ามี); ถ้าไม่มีโทรศัพท์ให้ลงที่ตั้ง |

```text
ที่ ศธ ๐๒๑๐/

          ด้วยสำนักงานปลัดกระทรวงศึกษาธิการขอส่งสำเนาประกาศกระทรวงศึกษาธิการ เรื่อง ปฏิทินการศึกษา
ปีการศึกษา ๒๕๗๐ มาเพื่อทราบ และแจ้งสถานศึกษาในสังกัดทราบต่อไปด้วย รายละเอียดปรากฏตามสิ่งที่ส่งมาพร้อมนี้

                                  สำนักงานปลัดกระทรวงศึกษาธิการ
                                        [ตราชื่อส่วนราชการ]
                                       ๒๑ พฤศจิกายน ๒๕๖๙
สำนักนโยบายและยุทธศาสตร์
โทร. ๐ ๒๖๒๘ ๕๖๔๖
```
