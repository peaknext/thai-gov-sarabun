# หนังสือสั่งการ: คำสั่ง · ระเบียบ · ข้อบังคับ (แบบที่ ๔ / ๕ / ๖ · ระเบียบข้อ ๑๕–๑๘)

หนังสือสั่งการให้ใช้ตามแบบในระเบียบนี้ **เว้นแต่จะมีกฎหมายกำหนดแบบไว้โดยเฉพาะ** (ข้อ ๑๕) — ทั้งสามแบบใช้กระดาษตราครุฑ
ไม่มีชั้นความเร็ว/ชั้นความลับในแบบฟอร์ม ไม่มีคำขึ้นต้น/คำลงท้าย

| | คำสั่ง | ระเบียบ | ข้อบังคับ |
|---|---|---|---|
| นิยาม | บรรดาข้อความที่ผู้บังคับบัญชาสั่งการให้ปฏิบัติโดยชอบด้วยกฎหมาย | บรรดาข้อความที่ผู้มีอำนาจหน้าที่วางไว้ โดยจะอาศัยอำนาจของกฎหมายหรือไม่ก็ได้ เพื่อถือเป็นหลักปฏิบัติงานเป็นการประจำ | บรรดาข้อความที่ผู้มีอำนาจหน้าที่กำหนดให้ใช้ โดยอาศัยอำนาจของกฎหมายที่บัญญัติให้กระทำได้ |
| ตัวอย่างการใช้ | แต่งตั้งคณะกรรมการ มอบหมายงาน แต่งตั้งโยกย้าย มอบอำนาจ | หลักเกณฑ์การใช้รถราชการ การลา การใช้ห้องประชุม | ข้อบังคับที่กฎหมายจัดตั้งองค์กรให้อำนาจออก |
| อ้างอำนาจกฎหมาย | อ้าง "ถ้ามี" | อ้าง "ถ้ามี" | **ต้องอ้าง** |
| เลขที่/ฉบับ | ที่ เลขลำดับ/ปี พ.ศ. | ฉบับที่ (ถ้าแก้ไขเพิ่มเติม) + พ.ศ. | ฉบับที่ (ถ้าแก้ไขเพิ่มเติม) + พ.ศ. |
| ท้าย | สั่ง ณ วันที่ | ประกาศ ณ วันที่ | ประกาศ ณ วันที่ |

## คำสั่ง (แบบที่ ๔ · ข้อ ๑๖)

```text
                                   [ครุฑ ๓ ซม.]
                  คำสั่ง(ชื่อส่วนราชการหรือตำแหน่งของผู้มีอำนาจที่ออกคำสั่ง)
                       ที่ ........../(เลขปีพุทธศักราชที่ออกคำสั่ง)
                       เรื่อง ...........................................
                                   ____________

          (ข้อความ) ...................................................................
.................................................................................
          ทั้งนี้ ตั้งแต่ ................................................................

                สั่ง ณ วันที่ ................................. พ.ศ. ............

                               (ลงชื่อ)
                                        (พิมพ์ชื่อเต็ม)
                                          (ตำแหน่ง)
```

| ส่วน | วิธีกรอก |
|---|---|
| คำสั่ง | ชื่อส่วนราชการ หรือตำแหน่งของผู้มีอำนาจที่ออกคำสั่ง — `คำสั่งกรมส่งเสริมการเรียนรู้` / `คำสั่งจังหวัดขอนแก่น` / `คำสั่งสำนักนายกรัฐมนตรี` |
| ที่ | เลขที่ออกคำสั่ง เริ่มฉบับแรกจากเลข ๑ เรียงไปจนสิ้นปีปฏิทิน ทับเลขปี พ.ศ. — `ที่ ๑๒๕/๒๕๖๙` |
| เรื่อง | ชื่อเรื่องที่ออกคำสั่ง — `แต่งตั้งคณะกรรมการ…` (คำสั่งนิยมขึ้นต้นเรื่องด้วยคำกริยา: แต่งตั้ง มอบหมาย ให้…) |
| ข้อความ | **อ้างเหตุที่ออกคำสั่ง** และ **อ้างอำนาจที่ให้ออกคำสั่ง (ถ้ามี)** แล้วจึงลงข้อความที่สั่ง และวันใช้บังคับ |
| ทั้งนี้ ตั้งแต่ | วันใช้บังคับ — `ทั้งนี้ ตั้งแต่บัดนี้เป็นต้นไป` / `ทั้งนี้ ตั้งแต่วันที่ ๑ ธันวาคม พ.ศ. ๒๕๖๙ เป็นต้นไป` |
| สั่ง ณ วันที่ | ตัวเลขวันที่ ชื่อเต็มของเดือน ตัวเลขปี พ.ศ. — `สั่ง ณ วันที่ ๒๑ พฤศจิกายน พ.ศ. ๒๕๖๙` |
| ลงชื่อ / ตำแหน่ง | ลายมือชื่อผู้ออกคำสั่ง พิมพ์ชื่อเต็มใต้ลายมือชื่อ และตำแหน่งผู้ออกคำสั่ง |

โครงข้อความคำสั่งที่นิยม (คำสั่งแต่งตั้งคณะกรรมการ):

```text
          ด้วย/โดยที่ (เหตุผลความจำเป็น) …………………… เพื่อให้ ……………………
          อาศัยอำนาจตามความใน (มาตรา … แห่งพระราชบัญญัติ… / ข้อ … แห่งระเบียบ…) จึงแต่งตั้งคณะกรรมการ…… ประกอบด้วย
          ๑. (ชื่อ ตำแหน่ง)                                   ประธานกรรมการ
          ๒. (ชื่อ ตำแหน่ง)                                   กรรมการ
          ๓. (ชื่อ ตำแหน่ง)                                   กรรมการและเลขานุการ
          ให้คณะกรรมการมีอำนาจหน้าที่ ดังนี้
          ๑. ……………………
          ๒. ……………………
          ทั้งนี้ ตั้งแต่บัดนี้เป็นต้นไป
```

## ระเบียบ (แบบที่ ๕ · ข้อ ๑๗) และ ข้อบังคับ (แบบที่ ๖ · ข้อ ๑๘)

```text
                                   [ครุฑ ๓ ซม.]
                     ระเบียบ(ชื่อส่วนราชการที่ออกระเบียบ)        ← ข้อบังคับ: "ข้อบังคับ(ชื่อส่วนราชการ)"
                     ว่าด้วย ...........................................
                     (ฉบับที่ ... ถ้ามีเรื่องเดียวกันเกินกว่า ๑ ฉบับ)
                               พ.ศ. ..............
                                   ____________

          (ข้อความ) ให้อ้างเหตุผลโดยย่อเพื่อแสดงถึงความมุ่งหมายที่ต้องออกระเบียบ และอ้างถึง
กฎหมายที่ให้อำนาจออกระเบียบ (ถ้ามี)
          ข้อ ๑  ระเบียบนี้เรียกว่า “ระเบียบ.................................. พ.ศ. .........”
          ข้อ ๒  ระเบียบนี้ให้ใช้บังคับตั้งแต่ .................................... เป็นต้นไป
          ......................................................................
          ข้อ (สุดท้าย) ผู้รักษาการตามระเบียบ (ถ้ามีการแบ่งเป็นหมวดให้นำข้อผู้รักษาการตามระเบียบไป
กำหนดเป็นข้อสุดท้ายก่อนที่จะขึ้นหมวด ๑)

                ประกาศ ณ วันที่ ................................. พ.ศ. ............
                               (ลงชื่อ)
                                        (พิมพ์ชื่อเต็ม)
                                          (ตำแหน่ง)
```

| ส่วน | วิธีกรอก |
|---|---|
| ระเบียบ / ข้อบังคับ | ชื่อส่วนราชการที่ออก |
| ว่าด้วย | ชื่อของระเบียบ/ข้อบังคับ |
| ฉบับที่ | ครั้งแรก **ไม่ต้องลง**; ถ้าเป็นเรื่องเดียวกันที่แก้ไขเพิ่มเติม ลง "(ฉบับที่ ๒)" และที่ถัด ๆ ไปตามลำดับ |
| พ.ศ. | ตัวเลขปี พ.ศ. ที่ออก |
| ข้อความ (อารัมภบท) | อ้างเหตุผลโดยย่อเพื่อแสดงความมุ่งหมาย และอ้างกฎหมายที่ให้อำนาจ (ระเบียบ: ถ้ามี / ข้อบังคับ: ต้องมี) — นิยมรูป "โดยที่เป็นการสมควร… อาศัยอำนาจตามความใน… (ผู้ออก) จึงวางระเบียบไว้ ดังต่อไปนี้" (ข้อบังคับ: "…จึงออกข้อบังคับไว้ ดังต่อไปนี้") |
| ข้อ | เรียงเป็นข้อ ๆ: **ข้อ ๑ ชื่อ** ("ระเบียบนี้เรียกว่า “…พ.ศ. …”") · **ข้อ ๒ วันใช้บังคับ** · ข้อถัดไปเนื้อหา (ถ้าเคยมีระเบียบเดิม นิยมมีข้อ "ให้ยกเลิก…") · **ข้อสุดท้าย ผู้รักษาการ** — ถ้ามีมากข้อหรือหลายเรื่องแบ่งเป็นหมวดได้ โดยย้ายข้อผู้รักษาการไปเป็นข้อสุดท้ายก่อนขึ้นหมวด ๑ |
| ประกาศ ณ วันที่ | วันที่ ชื่อเต็มของเดือน ปี พ.ศ. |
| ลงชื่อ / ตำแหน่ง | ผู้ออกระเบียบ/ข้อบังคับ |

## จุดตรวจเฉพาะ

- คำสั่ง: มีทั้ง "เหตุ" "อำนาจ (ถ้ามี)" "สิ่งที่สั่ง" "วันใช้บังคับ" ครบ; เลขที่เป็น ลำดับ/พ.ศ.
- ระเบียบ/ข้อบังคับ: ข้อ ๑ = ชื่อ (ชื่อในเครื่องหมายคำพูดต้องตรงกับหัวเรื่อง + พ.ศ.), ข้อ ๒ = วันใช้บังคับ, ข้อสุดท้าย = ผู้รักษาการ
- ข้อบังคับต้องอ้างกฎหมายที่ให้อำนาจเสมอ ถ้าผู้ใช้ไม่ระบุ ให้เว้น `[ระบุมาตรา/กฎหมายที่ให้อำนาจ]` และแจ้งผู้ใช้
