# หนังสือภายนอก (แบบที่ ๑ · ระเบียบข้อ ๑๑)

หนังสือติดต่อราชการที่เป็นแบบพิธี ใช้กระดาษตราครุฑ — ระหว่างส่วนราชการ หรือส่วนราชการมีถึงหน่วยงานอื่นซึ่งมิใช่ส่วนราชการ หรือถึงบุคคลภายนอก

## โครงร่างตามแบบที่ ๑ (ถอดจากแบบท้ายระเบียบ)

```text
                              ชั้นความลับ (ถ้ามี)
                                   [ครุฑ ๓ ซม.]
ชั้นความเร็ว (ถ้ามี)
ที่ ..........................                        (ส่วนราชการเจ้าของหนังสือ)
                                                      (ที่ตั้ง)
                                    (วัน เดือน ปี)
เรื่อง  ................................................
(คำขึ้นต้น) ...........
อ้างถึง  (ถ้ามี)
สิ่งที่ส่งมาด้วย  (ถ้ามี)
                (ข้อความ) ...................................................
.............................................................................
                                         (คำลงท้าย)

                                (ลงชื่อ)
                                        (พิมพ์ชื่อเต็ม)
                                          (ตำแหน่ง)
(ส่วนราชการเจ้าของเรื่อง)
โทร. ...................
โทรสาร .................
สำเนาส่ง (ถ้ามี)
                              ชั้นความลับ (ถ้ามี)
```

ตำแหน่งตามแบบ: ครุฑกึ่งกลางบน · "ที่" ชิดซ้าย บรรทัดเดียวกับส่วนราชการเจ้าของหนังสือซึ่งชิดขวา · วัน เดือน ปี เริ่มประมาณกึ่งกลางหน้า ·
เรื่อง / คำขึ้นต้น / อ้างถึง / สิ่งที่ส่งมาด้วย ชิดซ้าย · ข้อความย่อหน้า · คำลงท้าย ชื่อเต็ม ตำแหน่ง อยู่แนวกึ่งกลางเดียวกัน (ค่อนขวาเล็กน้อย)
"(ลงชื่อ)" คือที่ว่างสำหรับลายมือชื่อระหว่างคำลงท้ายกับชื่อเต็ม · บล็อกผู้ติดต่อชิดซ้ายล่าง

## วิธีกรอกแต่ละส่วน (ข้อ ๑๑.๑–๑๑.๑๔)

| ส่วน | วิธีกรอก |
|---|---|
| ที่ | รหัสตัวพยัญชนะ + เลขประจำของเจ้าของเรื่อง (ภาคผนวก ๑) **ทับ** เลขทะเบียนหนังสือส่ง เช่น `ที่ อว ๐๒๐๑/๑๒๓๔` — เลขทะเบียนส่งออกโดยหน่วยสารบรรณกลาง ถ้าผู้ใช้ไม่ให้ ให้เว้นไว้ `ที่ อว ๐๒๐๑/` |
| ส่วนราชการเจ้าของหนังสือ | ชื่อส่วนราชการ สถานที่ราชการ หรือคณะกรรมการเจ้าของหนังสือ และ **โดยปกติให้ลงที่ตั้งไว้ด้วย** (เช่น ถนน เขต จังหวัด รหัสไปรษณีย์) |
| วัน เดือน ปี | ตัวเลขวันที่ ชื่อเต็มของเดือน ตัวเลขปี พ.ศ. ที่ออกหนังสือ — `๒๑ พฤศจิกายน ๒๕๖๙` |
| เรื่อง | เรื่องย่อที่เป็นใจความสั้นที่สุด; หนังสือต่อเนื่องโดยปกติใช้เรื่องเดิม |
| คำขึ้นต้น | ตามฐานะผู้รับ (`../salutations.md`) แล้วลง **ตำแหน่ง** ผู้รับ หรือชื่อบุคคลถ้าไม่เกี่ยวกับตำแหน่ง — `เรียน อธิบดีกรมควบคุมโรค` |
| อ้างถึง (ถ้ามี) | อ้างหนังสือที่ **ผู้รับได้รับมาก่อนแล้ว** — ลงชื่อส่วนราชการเจ้าของหนังสือ เลขที่ วันที่ เดือน ปี พ.ศ. — `หนังสือกรมควบคุมโรค ที่ สธ ๐๔๐๒/๕๖๗ ลงวันที่ ๓ พฤศจิกายน ๒๕๖๙` · อ้างฉบับสุดท้ายฉบับเดียว เว้นแต่มีสาระสำคัญต้องอ้างฉบับอื่นด้วย |
| สิ่งที่ส่งมาด้วย (ถ้ามี) | ชื่อสิ่งของ เอกสาร หรือบรรณสารที่ส่งไปพร้อมหนังสือ (นิยมระบุจำนวน เช่น "จำนวน ๑ ชุด"); หลายรายการให้ใส่เลข ๑. ๒. ; ส่งแยกต่างหากให้แจ้งว่าส่งโดยทางใด |
| ข้อความ | สาระสำคัญชัดเจน เข้าใจง่าย หากมีความประสงค์หลายประการให้แยกเป็นข้อ ๆ (โครงสร้าง ๓ ส่วน ดู `../writing-style.md`) |
| คำลงท้าย | ตามฐานะผู้รับ — คู่กับคำขึ้นต้น (`ขอแสดงความนับถือ` / `ขอแสดงความนับถืออย่างยิ่ง`) |
| ลงชื่อ | ลายมือชื่อเจ้าของหนังสือ แล้วพิมพ์ชื่อเต็มในวงเล็บใต้ลายมือชื่อ ตามภาคผนวก ๓ (`../signing.md`) — `(นายสมชาย ใจดี)` |
| ตำแหน่ง | ตำแหน่งของเจ้าของหนังสือ; ลงชื่อแทนให้ใส่ "ปฏิบัติราชการแทน/รักษาราชการแทน …" บรรทัดถัดไป |
| ส่วนราชการเจ้าของเรื่อง | ถ้าผู้ออกหนังสืออยู่ระดับกระทรวง/ทบวง ลงทั้งระดับกรมและกอง; ถ้าระดับกรมลงมา ลงเพียงระดับกองหรือหน่วยงานที่รับผิดชอบ |
| โทร. | หมายเลขโทรศัพท์ของส่วนราชการเจ้าของเรื่อง และหมายเลขภายใน (ถ้ามี); แบบพิมพ์มี "โทรสาร" ด้วย ปัจจุบันนิยมเพิ่ม "ไปรษณีย์อิเล็กทรอนิกส์" (อีเมลกลาง saraban@…) |
| สำเนาส่ง (ถ้ามี) | ชื่อเต็มหรือชื่อย่อส่วนราชการ/บุคคลที่ส่งสำเนาให้; ถ้ามีมากให้พิมพ์ว่า "ส่งไปตามรายชื่อที่แนบ" และแนบรายชื่อ |

## ตัวอย่างร่าง (ข้อความล้วน)

```text
ด่วนที่สุด                         [ครุฑ]
ที่ สธ ๐๒๐๑/                                         สำนักงานปลัดกระทรวงสาธารณสุข
                                                     ถนนติวานนท์ จังหวัดนนทบุรี ๑๑๐๐๐
                                  ๒๑ พฤศจิกายน ๒๕๖๙
เรื่อง  ขอเชิญเป็นวิทยากร
เรียน  อธิบดีกรมควบคุมโรค
สิ่งที่ส่งมาด้วย  ๑. กำหนดการประชุม               จำนวน ๑ ชุด
                 ๒. แบบตอบรับ                     จำนวน ๑ ฉบับ

          ด้วยสำนักงานปลัดกระทรวงสาธารณสุข กำหนดจัดการประชุมเชิงปฏิบัติการด้านการเฝ้าระวัง
โรคติดต่ออุบัติใหม่ ระหว่างวันที่ ๑๕ – ๑๖ ธันวาคม ๒๕๖๙ ณ จังหวัดนนทบุรี เพื่อพัฒนาศักยภาพบุคลากร...
          ในการนี้ สำนักงานปลัดกระทรวงสาธารณสุขพิจารณาแล้วเห็นว่า นายแพทย์ประสิทธิ์ รักษ์ไทย
ผู้อำนวยการกองระบาดวิทยา เป็นผู้มีความรู้และประสบการณ์ในเรื่องดังกล่าวเป็นอย่างดี จึงขอเรียนเชิญ
เป็นวิทยากรบรรยายในหัวข้อ “...” ในวันที่ ๑๕ ธันวาคม ๒๕๖๙ เวลา ๐๙.๐๐ – ๑๒.๐๐ น.
รายละเอียดปรากฏตามสิ่งที่ส่งมาด้วย
          จึงเรียนมาเพื่อโปรดพิจารณาอนุญาต และขอขอบคุณมา ณ โอกาสนี้

                                     ขอแสดงความนับถือ

                                     (นายสมชาย ใจดี)
                                 รองปลัดกระทรวงสาธารณสุข
                           ปฏิบัติราชการแทนปลัดกระทรวงสาธารณสุข
กองยุทธศาสตร์และแผนงาน
โทร. ๐ ๒๕๙๐ ๑๒๓๔
ไปรษณีย์อิเล็กทรอนิกส์ saraban@moph.go.th
```

ไฟล์ spec สำหรับสร้าง docx ของตัวอย่างนี้: `assets/examples/01-external-letter.json`

## จุดตรวจเฉพาะหนังสือภายนอก

- มี "ที่" + ส่วนราชการเจ้าของหนังสือ (พร้อมที่ตั้ง) + วันที่ + เรื่อง + คำขึ้นต้น + ข้อความ + คำลงท้าย + ชื่อ/ตำแหน่ง + ส่วนราชการเจ้าของเรื่อง/โทร. ครบ
- คำขึ้นต้น–คำลงท้ายเข้าคู่กันตามฐานะผู้รับ
- "อ้างถึง" ใช้เฉพาะหนังสือที่ผู้รับเคยได้รับแล้ว — ถ้าเป็นเอกสารที่แนบไปครั้งนี้ ให้ใช้ "สิ่งที่ส่งมาด้วย"
- ถ้ามีอ้างถึงหรือสิ่งที่ส่งมาด้วย ให้กล่าวถึงในเนื้อความด้วย ("ตามหนังสือที่อ้างถึง…", "…รายละเอียดปรากฏตามสิ่งที่ส่งมาด้วย")
