# หนังสือที่เจ้าหน้าที่ทำขึ้นหรือรับไว้เป็นหลักฐานในราชการ (ระเบียบข้อ ๒๓–๒๗)

มี ๔ ชนิด: **หนังสือรับรอง** (แบบที่ ๑๐) · **รายงานการประชุม** (แบบที่ ๑๑) · **บันทึก** (ดู `internal-memo.md`) · **หนังสืออื่น**

## หนังสือรับรอง (แบบที่ ๑๐ · ข้อ ๒๔)

หนังสือที่ส่วนราชการออกให้เพื่อรับรองแก่บุคคล นิติบุคคล หรือหน่วยงาน เพื่อวัตถุประสงค์อย่างหนึ่งอย่างใดให้ปรากฏแก่บุคคลโดยทั่วไป
**ไม่จำเพาะเจาะจง** — ใช้กระดาษตราครุฑ ไม่มีเรื่อง คำขึ้นต้น คำลงท้าย

```text
                                   [ครุฑ ๓ ซม.]
  เลขที่ ............                                 (ส่วนราชการเจ้าของหนังสือ)

          (ข้อความ) หนังสือฉบับนี้ให้ไว้เพื่อรับรองว่า (ระบุชื่อบุคคล นิติบุคคลหรือหน่วยงานที่จะให้
การรับรองพร้อมทั้งลงตำแหน่งและสังกัด หรือที่ตั้ง แล้วต่อด้วยข้อความที่รับรอง) ..........................

                   ให้ไว้ ณ วันที่ ...................... พ.ศ. ...........

(ส่วนนี้ใช้สำหรับเรื่องสำคัญ)                (ลงชื่อ)
+-----------+                                 (พิมพ์ชื่อเต็ม)
|  รูปถ่าย   |                                   (ตำแหน่ง)
|  (ถ้ามี)   |
+-----------+ (ประทับตราชื่อส่วนราชการ)
(ลงชื่อผู้ได้รับการรับรอง)
   (พิมพ์ชื่อเต็ม)
```

| ส่วน | วิธีกรอก |
|---|---|
| เลขที่ | เลขที่หนังสือรับรองโดยเฉพาะ เริ่ม ๑ เรียงไปจนสิ้นปีปฏิทิน ทับเลขปี พ.ศ. (`๑๕/๒๕๖๙`) หรือใช้เลขหนังสือทั่วไปแบบหนังสือภายนอก |
| ส่วนราชการเจ้าของหนังสือ | ชื่อส่วนราชการเจ้าของหนังสือ จะลงที่ตั้งด้วยก็ได้ |
| ข้อความ | ขึ้นต้นว่า **"หนังสือฉบับนี้ให้ไว้เพื่อรับรองว่า"** แล้วต่อด้วยชื่อบุคคล นิติบุคคล หรือหน่วยงาน — ถ้าเป็นบุคคลให้พิมพ์ชื่อเต็มโดยมีคำนำหน้านาม ชื่อ นามสกุล ตำแหน่งหน้าที่ และสังกัดอย่างชัดแจ้ง แล้วจึงลงข้อความที่รับรอง |
| ให้ไว้ ณ วันที่ | ตัวเลขวันที่ ชื่อเต็มของเดือน ตัวเลขปี พ.ศ. |
| ลงชื่อ | ลายมือชื่อหัวหน้าส่วนราชการผู้ออกหนังสือ หรือผู้ที่ได้รับมอบหมาย และพิมพ์ชื่อเต็มใต้ลายมือชื่อ |
| ตำแหน่ง | ตำแหน่งของผู้ลงลายมือชื่อ |
| รูปถ่าย (เรื่องสำคัญที่ออกให้บุคคล) | ติดรูปถ่ายขนาด **๔ × ๖ เซนติเมตร** หน้าตรง ไม่สวมหมวก ประทับตราชื่อส่วนราชการบนขอบล่างด้านขวาของรูปคาบต่อลงบนกระดาษ ให้ผู้นั้นลงลายมือชื่อใต้รูปพร้อมพิมพ์ชื่อเต็ม |

ไม่ควรเขียนจำเพาะผู้รับ เช่น "เรียน ผู้จัดการธนาคาร…" — ถ้าผู้ใช้ต้องการส่งถึงหน่วยงานเฉพาะ ให้ใช้หนังสือภายนอกแทน

## รายงานการประชุม (แบบที่ ๑๑ · ข้อ ๒๕)

การบันทึกความคิดเห็นของผู้มาประชุม ผู้เข้าร่วมประชุม และมติของที่ประชุมไว้เป็นหลักฐาน — แบบที่ ๑๑ ไม่มีครุฑ

```text
                   รายงานการประชุม ...................................
                              ครั้งที่ ................
                         เมื่อ ..................................
                          ณ ..................................
                                   ____________
ผู้มาประชุม
ผู้ไม่มาประชุม (ถ้ามี)
ผู้เข้าร่วมประชุม (ถ้ามี)
เริ่มประชุมเวลา
          (ข้อความ) ...................................................................
เลิกประชุมเวลา
                                         .........................................
                                              ผู้จดรายงานการประชุม
```

(หัวข้อ ผู้มาประชุม ฯลฯ ในแบบพิมพ์ขีดเส้นใต้)

| ส่วน | วิธีกรอก |
|---|---|
| รายงานการประชุม | ชื่อคณะที่ประชุมหรือชื่อการประชุม |
| ครั้งที่ | ครั้งที่ประชุม — นิยม `๓/๒๕๖๙` |
| เมื่อ | วัน เดือน ปีที่ประชุม — นิยม `วันพฤหัสบดีที่ ๒๐ พฤศจิกายน ๒๕๖๙` |
| ณ | สถานที่ประชุม |
| ผู้มาประชุม | ชื่อและหรือตำแหน่งของผู้ได้รับแต่งตั้งเป็นคณะที่ประชุมซึ่งมาประชุม; ผู้มาประชุมแทนให้ลงชื่อผู้มาแทนและว่ามาแทนผู้ใด/ตำแหน่งใด |
| ผู้ไม่มาประชุม | ชื่อและหรือตำแหน่งของผู้ได้รับแต่งตั้งซึ่งมิได้มาประชุม พร้อมเหตุผล (ถ้ามี) เช่น "ติดราชการ" "ลาป่วย" |
| ผู้เข้าร่วมประชุม | ชื่อและหรือตำแหน่งของผู้ที่มิได้รับแต่งตั้งเป็นคณะที่ประชุมซึ่งเข้าร่วมประชุม (ถ้ามี) |
| เริ่มประชุมเวลา | เวลาที่เริ่ม — `๐๙.๓๐ น.` |
| ข้อความ | โดยปกติเริ่มด้วยประธานกล่าวเปิดประชุม แล้วเรื่องที่ประชุม กับมติหรือข้อสรุปของที่ประชุมในแต่ละเรื่องตามลำดับ |
| เลิกประชุมเวลา | เวลาที่เลิก |
| ผู้จดรายงานการประชุม | ชื่อผู้จดรายงานการประชุมครั้งนั้น (นิยมเพิ่ม "ผู้ตรวจรายงานการประชุม" ได้) |

ลำดับระเบียบวาระที่นิยม: ระเบียบวาระที่ ๑ เรื่องที่ประธานแจ้งให้ที่ประชุมทราบ · ๒ รับรองรายงานการประชุมครั้งที่แล้ว ·
๓ เรื่องสืบเนื่อง · ๔ เรื่องเพื่อทราบ · ๕ เรื่องเพื่อพิจารณา · ๖ เรื่องอื่น ๆ (ถ้ามี) — ทุกวาระปิดด้วย **"มติที่ประชุม …"**

รายงานการประชุมเขียนเป็น **อดีตกาล บุรุษที่ ๓** สรุปสาระ ไม่ใช่ถอดคำพูดคำต่อคำ (เว้นแต่ที่ประชุมต้องการ):
"ประธานแจ้งว่า…" "ฝ่ายเลขานุการเสนอว่า…" "ที่ประชุมพิจารณาแล้วมีมติ…"

## หนังสืออื่น (ข้อ ๒๗)

หนังสือหรือเอกสารอื่นใดที่เกิดขึ้นเนื่องจากการปฏิบัติงานของเจ้าหน้าที่เพื่อเป็นหลักฐานในราชการ รวมถึงภาพถ่าย ฟิล์ม แถบบันทึกเสียง/ภาพ
และสื่อกลางบันทึกข้อมูล (รวมพื้นที่จัดเก็บข้อมูลอิเล็กทรอนิกส์ เช่น cloud computing) หรือหนังสือของบุคคลภายนอกที่ยื่นต่อเจ้าหน้าที่และลงทะเบียนรับแล้ว
มีรูปแบบตามที่กระทรวง ทบวง กรม กำหนด เว้นแต่มีแบบตามกฎหมายเฉพาะ เช่น โฉนด แผนที่ แบบ แผนผัง สัญญา หลักฐานการสืบสวนสอบสวน และคำร้อง
— ถ้าผู้ใช้ขอร่างเอกสารประเภทนี้ ให้ถามว่ามีแบบฟอร์มเฉพาะของหน่วยงาน/กฎหมายหรือไม่ก่อน
