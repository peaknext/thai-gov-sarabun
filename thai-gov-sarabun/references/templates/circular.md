# หนังสือเวียน (ระเบียบข้อ ๓๒) — รวมหนังสือเวียนภายในหน่วยงาน

**หนังสือเวียน** คือหนังสือที่มีถึงผู้รับเป็นจำนวนมาก มีใจความอย่างเดียวกัน — ไม่ใช่ชนิดหนังสือแยกต่างหาก
แต่เป็น **หนังสือภายนอก / หนังสือภายใน / หนังสือประทับตรา** ที่ส่งถึงผู้รับหลายราย โดยมีเครื่องหมายเฉพาะในเลขที่

## สิ่งที่ทำให้เป็นหนังสือเวียน

1. **เลขที่**: เพิ่มรหัสตัวพยัญชนะ **ว** หน้าเลขทะเบียนหนังสือส่ง — `ที่ สธ ๐๒๐๑/ว ๑๒๓`
   เลขเวียนเป็นชุดเฉพาะ เริ่ม ๑ เรียงไปจนสิ้นปีปฏิทิน หรือจะใช้เลขทั่วไปตามแบบหนังสือภายนอกก็ได้ (ข้อ ๓๒) — ถ้าไม่รู้เลขให้เว้น `ที่ สธ ๐๒๐๑/ว`
2. **คำขึ้นต้น**: เรียกผู้รับเป็นกลุ่มตามตำแหน่ง เช่น
   - ภายในหน่วยงาน: `เรียน ผู้อำนวยการกอง ทุกกอง` · `เรียน หัวหน้ากลุ่มงาน/หัวหน้างาน ทุกกลุ่มงาน` · `เรียน ข้าราชการ ลูกจ้าง และพนักงานราชการ ทุกคน`
   - ภายนอก: `เรียน หัวหน้าส่วนราชการระดับกรม` · `เรียน ผู้ว่าราชการจังหวัด ทุกจังหวัด` · `เรียน ผู้อำนวยการสำนักงานเขตพื้นที่การศึกษา ทุกเขต`
   - ถ้าผู้รับต่างฐานะกันมาก (บางรายต้อง "กราบเรียน") ให้แยกฉบับตามฐานะ ไม่ปนในฉบับเดียว
3. **ผู้รับจำนวนมาก**: ถ้าระบุรายชื่อไม่ได้ในคำขึ้นต้น ใช้ "เรียน ผู้รับตามบัญชีรายชื่อแนบท้าย" แล้ว **แนบบัญชีรายชื่อ**
   (หลักเดียวกับ "สำเนาส่ง … ส่งไปตามรายชื่อที่แนบ" ข้อ ๑๑.๑๔) — ใน build_docx ใช้ฟิลด์ `distribution`
4. **หน้าที่ของผู้รับ** (ข้อ ๓๒ วรรคสอง): ผู้รับที่เห็นว่าหน่วยงาน/บุคคลในบังคับบัญชาต้องทราบด้วย มีหน้าที่ทำสำเนาหรือจัดส่งต่อโดยเร็ว —
   หนังสือเวียนจึงมักปิดด้วย "…และแจ้งให้ (ผู้เกี่ยวข้อง) ในสังกัดทราบและถือปฏิบัติต่อไปด้วย"

## หนังสือเวียนภายในหน่วยงาน (ใช้กระดาษบันทึกข้อความ — แบบที่ ๒)

ใช้เมื่อผู้บังคับบัญชาหรือฝ่ายบริหารต้องแจ้งเรื่องเดียวกันถึงทุกกอง/กลุ่มงาน/บุคลากรในหน่วยงานเดียวกัน เช่น แจ้งแนวปฏิบัติ
ประชาสัมพันธ์การอบรม แจ้งวันหยุด ขอความร่วมมือส่งข้อมูล

```text
[ครุฑ ๑.๕ ซม.]                     บันทึกข้อความ
ส่วนราชการ  สำนักงานเลขานุการกรม กลุ่มบริหารทั่วไป โทร. ๐ ๒๕๙๐ ๑๑๐๐
ที่  สธ ๐๔๐๑/ว                              วันที่  ๒๑ พฤศจิกายน ๒๕๖๙
เรื่อง  แนวปฏิบัติการลาของข้าราชการผ่านระบบอิเล็กทรอนิกส์

เรียน  ผู้อำนวยการกอง/สำนัก ทุกกอง/สำนัก

          ด้วยกรม… ได้นำระบบการลาอิเล็กทรอนิกส์มาใช้ ตั้งแต่วันที่ ๑ ธันวาคม ๒๕๖๙ เพื่อ…
          ในการนี้ จึงขอให้ทุกหน่วยงานถือปฏิบัติ ดังนี้
          ๑. ……………………
          ๒. ……………………
          จึงเรียนมาเพื่อโปรดทราบ และแจ้งบุคลากรในสังกัดทราบและถือปฏิบัติต่อไปด้วย

                                       (นางสาว……………)
                                       เลขานุการกรม
```

- ผู้ลงนาม: ผู้มีอำนาจตามเรื่อง (เช่น เลขานุการกรม ผู้อำนวยการ) — เวียนในนามผู้บริหารสูงสุดให้ลงชื่อแทนตามที่ได้รับมอบ
- ไม่มีคำลงท้าย (เหมือนบันทึกข้อความทั่วไป)
- ถ้าผู้ส่งเป็นผู้บังคับบัญชาและผู้รับเป็นผู้ใต้บังคับบัญชาทั้งหมด ปิดได้ว่า "จึงแจ้งมาเพื่อทราบและถือปฏิบัติ" (ดู `../writing-style.md`)

## หนังสือเวียนภายนอก (แบบที่ ๑) และหนังสือเวียนประทับตรา (แบบที่ ๓)

เหมือนหนังสือภายนอก/ประทับตราทุกประการ ต่างกันเพียง: เลขที่มี `ว` · คำขึ้นต้นเป็นกลุ่มผู้รับ (หนังสือประทับตราใช้ "ถึง" แทน) ·
แนบบัญชีรายชื่อถ้าระบุไม่ได้ · ข้อความมักขอให้แจ้งต่อในสังกัด

## build_docx

```json
{
  "type": "internal",
  "number": "สธ ๐๔๐๑/ว",
  "salutation": "เรียน ผู้อำนวยการกอง/สำนัก ทุกกอง/สำนัก",
  "distribution": ["กองบริหารการคลัง", "กองบริหารทรัพยากรบุคคล", "…"],
  "distribution_title": "บัญชีรายชื่อหน่วยงานผู้รับ"
}
```

`distribution` (ถ้ามี) จะขึ้นหน้าใหม่เป็น "บัญชีรายชื่อผู้รับ แนบท้ายหนังสือ ที่ … ลงวันที่ …" ใช้ได้กับ external / internal / stamped
ตัวอย่างเต็ม: `assets/examples/11-internal-circular.json`

## จุดตรวจเฉพาะ

- เลขที่ต้องมี `ว` หน้าเลขทะเบียนส่ง (check_draft.py แจ้ง ERROR ถ้าเป็นหนังสือเวียนแต่ไม่มี `ว`)
- คำขึ้นต้นเป็นตำแหน่งของกลุ่มผู้รับ ไม่ใช่ชื่อบุคคล
- ระบุชัดว่าต้องการให้ผู้รับทำอะไร และให้แจ้งต่อหรือไม่
