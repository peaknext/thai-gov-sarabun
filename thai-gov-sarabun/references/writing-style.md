# ภาษาและสำนวนหนังสือราชการ

ระเบียบงานสารบรรณกำหนดเพียงว่า ข้อความต้อง "ชัดเจนและเข้าใจง่าย หากมีความประสงค์หลายประการให้แยกเป็นข้อ ๆ" (ข้อ ๑๑.๘)
เนื้อหาในไฟล์นี้จึงเป็น **แนวปฏิบัติที่ส่วนราชการใช้กันทั่วไป** (คู่มือการเขียนหนังสือราชการ หลักภาษาของราชบัณฑิตยสภา) ไม่ใช่ตัวบทระเบียบ
ใช้เพื่อให้ร่างอ่านเป็นภาษาราชการที่สุภาพ กระชับ และถูกต้อง

## หลักใหญ่ ๕ ข้อ

1. **ถูกต้อง** — ข้อเท็จจริง ตัวเลข วันที่ ชื่อ ตำแหน่ง ชื่อส่วนราชการ ถูกต้องครบถ้วน (ห้ามแต่งข้อเท็จจริงขึ้นเอง ใช้ `[...]` แทนข้อมูลที่ไม่มี)
2. **ชัดเจน** — หนึ่งย่อหน้าหนึ่งประเด็น บอกให้รู้ว่าต้องการให้ผู้รับทำอะไร ภายในเมื่อไร
3. **กระชับ** — ตัดคำฟุ่มเฟือย ไม่วกวน ไม่ซ้ำความ
4. **สุภาพ เป็นทางการ** — ใช้ภาษาเขียนระดับทางการ ไม่ใช้ภาษาพูด คำสแลง คำลงท้าย "ครับ/ค่ะ/นะ" หรืออีโมจิ
5. **เป็นกลาง** — ใช้นามส่วนราชการเป็นผู้พูด ("กรม…ขอเรียนว่า…") ไม่แสดงอารมณ์ส่วนตัว

## โครงสร้างเนื้อความ ๓ ส่วน

| ส่วน | หน้าที่ | คำขึ้นต้นย่อหน้าที่นิยม |
|---|---|---|
| **๑. เหตุที่มีหนังสือไป** (ความเป็นมา) | บอกที่มา/เหตุผล หรืออ้างเรื่องเดิม | **ด้วย** (เรื่องใหม่ที่ผู้ส่งริเริ่ม) · **เนื่องด้วย / เนื่องจาก** (มีเหตุจำเป็น) · **ตามที่** … **นั้น** (อ้างเรื่องที่ผู้รับรู้แล้ว) · **ตามหนังสือที่อ้างถึง** … **นั้น** · **อนุสนธิ**หนังสือ… (ต่อเนื่องเรื่องเดิม) · **โดยที่** (ใช้ในระเบียบ/คำสั่ง) |
| **๒. จุดประสงค์ / ข้อพิจารณา** | สิ่งที่ต้องการ ข้อเท็จจริง ข้อพิจารณา รายละเอียด | **ในการนี้** · **บัดนี้** · **จึง**… · **(ส่วนราชการ) พิจารณาแล้วเห็นว่า** · **ทั้งนี้** · **อนึ่ง** (เพิ่มเรื่องอื่นที่เกี่ยวข้อง) · **อย่างไรก็ดี** · **ดังนั้น** |
| **๓. ส่วนสรุป (ปิดท้าย)** | บอกว่าขอให้ผู้รับทำอะไร | **จึงเรียนมาเพื่อ…** / **จึงเรียนยืนยันมา…** / **จึงแจ้งมาเพื่อ…** (ดูตารางด้านล่าง) |

> "ตามที่ …… ความละเอียดแจ้งแล้ว **นั้น**" — เมื่อขึ้นต้นด้วย "ตามที่/ตามหนังสือที่อ้างถึง" ต้องปิดอนุประโยคด้วย "นั้น" เสมอ แล้วขึ้นย่อหน้าใหม่ด้วย "บัดนี้ / ในการนี้ / (ส่วนราชการ) ขอเรียนว่า"

## ประโยคปิดท้ายตามวัตถุประสงค์

| วัตถุประสงค์ | ถึงผู้บังคับบัญชา / ส่วนราชการอื่น / บุคคลภายนอก | ผู้บังคับบัญชาถึงผู้ใต้บังคับบัญชา |
|---|---|---|
| แจ้งให้ทราบ | จึงเรียนมาเพื่อโปรดทราบ | จึงแจ้งมาเพื่อทราบ |
| ขอให้พิจารณา | จึงเรียนมาเพื่อโปรดพิจารณา | จึงแจ้งมาเพื่อพิจารณา |
| ขออนุมัติ / อนุญาต | จึงเรียนมาเพื่อโปรดพิจารณาอนุมัติ / อนุญาต | – |
| ขอความอนุเคราะห์ / ความร่วมมือ | จึงเรียนมาเพื่อโปรดพิจารณาให้ความอนุเคราะห์ (ด้วย จะขอบคุณยิ่ง) / จึงเรียนมาเพื่อโปรดพิจารณาให้ความร่วมมือ | – |
| ขอให้ดำเนินการ | จึงเรียนมาเพื่อโปรดทราบและพิจารณาดำเนินการต่อไป | จึงแจ้งมาเพื่อทราบและดำเนินการต่อไป |
| ขอให้ถือปฏิบัติ | จึงเรียนมาเพื่อโปรดทราบและถือปฏิบัติต่อไป | จึงแจ้งมาเพื่อทราบและถือปฏิบัติ |
| ขอให้แจ้งต่อ | จึงเรียนมาเพื่อโปรดทราบ และแจ้งให้ (หน่วยงานในสังกัด) ทราบต่อไปด้วย | จึงแจ้งมาเพื่อทราบ และแจ้งผู้เกี่ยวข้องทราบต่อไป |
| ขอเชิญ | จึงเรียนมาเพื่อโปรดพิจารณาเข้าร่วม… / จึงเรียนเชิญ… | – |
| ขอบคุณ (ต่อท้าย) | …และขอขอบคุณมา ณ โอกาสนี้ / …จะขอบคุณยิ่ง (ใช้เมื่อขอความกรุณา) | – |
| ยืนยัน | จึงเรียนยืนยันมาเพื่อโปรดทราบ | – |
| บันทึกเสนอผู้บังคับบัญชาที่มีหนังสือแนบให้ลงนาม | จึงเรียนมาเพื่อโปรดพิจารณา หากเห็นชอบโปรดลงนามในหนังสือที่เสนอมาพร้อมนี้ | – |
| หนังสือประทับตรา (ไม่มีคำขึ้นต้น) | …มาเพื่อทราบ / …มาเพื่อดำเนินการต่อไป / …มาเพื่อโปรดทราบ | – |
| ประกาศ | จึงประกาศมาเพื่อทราบโดยทั่วกัน / จึงประกาศให้ทราบโดยทั่วกัน | – |

"โปรด" ใช้กับผู้ที่สูงกว่าหรือเสมอกันเพื่อความสุภาพ · "กรุณา" ใช้เมื่อขอให้ผู้รับทำบางอย่างให้ ("กรุณาแจ้งผล…ภายในวันที่…")

## คำ/สำนวนที่ควรใช้แทนภาษาพูด

| ภาษาพูด / ไม่เป็นทางการ | ภาษาราชการ |
|---|---|
| บอก, บอกให้รู้ | แจ้ง, เรียนให้ทราบ |
| ขอให้ช่วย | ขอความอนุเคราะห์, ขอความร่วมมือ |
| ส่งมาให้ | ส่ง…มาเพื่อ…, ขอส่ง…มาพร้อมนี้ |
| อยากให้ / อยากจะ | ประสงค์จะ, มีความประสงค์ |
| ได้รับแล้ว | ได้รับ…เรียบร้อยแล้ว |
| เยอะ, มากมาย | จำนวนมาก |
| ตอนนี้ | ขณะนี้, ปัจจุบัน |
| ถ้า | หาก, ในกรณีที่ |
| แต่ว่า | แต่, อย่างไรก็ตาม, อย่างไรก็ดี |
| เพราะว่า | เนื่องจาก, เพราะ |
| เรื่องนี้ | เรื่องดังกล่าว |
| เอาไป, ใช้ไป | นำไป, ใช้ |
| ไม่ได้ (ปฏิเสธ) | ไม่อาจ…ได้, ไม่สามารถ…ได้ (ปฏิเสธอย่างสุภาพ: "…จึงขออภัยที่ไม่อาจ…ได้ในครั้งนี้") |
| ขอบคุณมาก | ขอขอบคุณมา ณ โอกาสนี้ |
| ประชุมกัน | ประชุมหารือ |
| เช็ค, อัปเดต, ฟีดแบ็ก | ตรวจสอบ, ปรับปรุงให้เป็นปัจจุบัน, ข้อคิดเห็น |
| ไหม / หรือเปล่า | หรือไม่ |
| ทาง (หน่วยงาน) จะ | (หน่วยงาน) จะ — ไม่ต้องใช้ "ทาง" นำหน้า |

## ระดับคำตามผู้รับ

- ผู้รับสูงกว่า: "ขอความกรุณา" "ขอประทานอนุญาต" (กับเชื้อพระวงศ์) "โปรดพิจารณา" — เรียกผู้รับว่า "ท่าน"
- ถึงพระภิกษุ: "นมัสการ" "พระคุณเจ้า/พระคุณท่าน" "ถวาย" (ไม่ใช่ "ให้") "อาราธนา" (เชิญพระ) "นิมนต์"
- ถึงพระราชวงศ์: ใช้ราชาศัพท์ให้ถูกชั้นพระยศ (ภาคผนวก ๒ หมายเหตุ ๒) — ควรให้ผู้ใช้ตรวจสอบกับสำนักพระราชวัง

## ตัวเลข วันเวลา เงิน (แนวปฏิบัติ)

- ใช้เลขไทยทั้งฉบับให้สม่ำเสมอ (ไม่ผสมกับเลขอารบิก) ยกเว้นอีเมล URL ชื่อไฟล์ รหัสภาษาอังกฤษ
- วันที่: `๒๑ พฤศจิกายน ๒๕๖๙` · ช่วงวันที่: `ระหว่างวันที่ ๑๕ – ๑๖ ธันวาคม ๒๕๖๙`
- เวลา: `เวลา ๐๙.๓๐ น.` / `เวลา ๐๙.๐๐ – ๑๒.๐๐ น.` (ใช้จุด ไม่ใช้ทวิภาค)
- จำนวนเงิน: `เป็นเงิน ๓,๖๐๐ บาท (สามพันหกร้อยบาทถ้วน)` — มีสตางค์: `๑,๒๕๐.๕๐ บาท (หนึ่งพันสองร้อยห้าสิบบาทห้าสิบสตางค์)`
- โทรศัพท์: `โทร. ๐ ๒๒๘๓ ๔๒๔๔` · อีเมลเขียนด้วยอักษรโรมันและเลขอารบิก
- ปีงบประมาณ: `ปีงบประมาณ พ.ศ. ๒๕๗๐`

## การเว้นวรรค (หลักราชบัณฑิตยสภาที่ใช้บ่อย)

- เว้นวรรค **หน้าและหลัง** ไม้ยมก: `ต่าง ๆ`, `ข้อ ๆ` · หน้าและหลัง `ฯลฯ` · หลัง `ฯ` ที่ย่อชื่อ (`กรุงเทพฯ ` )
- เว้นวรรคระหว่างประโยค ระหว่างชื่อกับนามสกุล ระหว่างคำนำหน้ากับตัวเลข (`ข้อ ๑`, `มาตรา ๓๒`, `ฉบับที่ ๒`)
- เว้นวรรคหน้า "และ" "หรือ" เมื่อเชื่อมรายการยาว ๆ เพื่อให้อ่านง่าย (ไม่บังคับ)
- **ไม่เว้นวรรค** ระหว่างคำนำหน้านามกับชื่อ (`นายสมชาย`) แต่ **เว้นวรรค** หลังคำย่อที่ตามด้วยตัวเลข และหน้าหน่วย (`พ.ศ. ๒๕๖๙`, `๐๙.๓๐ น.`, `๓,๖๐๐ บาท`)
- หลังคำขึ้นต้น/หัวข้อ เว้น ๑–๒ เคาะ: `เรื่อง  ขอเชิญ…` `เรียน  อธิบดี…`

## คำย่อ

- หลีกเลี่ยงคำย่อในเนื้อความ — ครั้งแรกเขียนเต็มแล้ววงเล็บคำย่อ: "สำนักงานคณะกรรมการพัฒนาระบบราชการ (สำนักงาน ก.พ.ร.)" ครั้งต่อไปใช้คำย่อได้
- คำย่อมาตรฐานที่ใช้ได้: พ.ศ. น. (นาฬิกา) โทร. กทม. (ในที่อยู่)

## แม่แบบย่อหน้าที่ใช้บ่อย

**ขอเชิญประชุม**
> ด้วย (ส่วนราชการ) กำหนดจัดประชุม (ชื่อการประชุม) ครั้งที่ … ในวัน… ที่ … เวลา … น. ณ … เพื่อ (วัตถุประสงค์)
> ในการนี้ จึงขอเรียนเชิญท่าน/ผู้แทน (ส่วนราชการ) เข้าร่วมประชุมตามวัน เวลา และสถานที่ดังกล่าว รายละเอียดปรากฏตามสิ่งที่ส่งมาด้วย
> จึงเรียนมาเพื่อโปรดพิจารณาเข้าร่วมประชุมตามวัน เวลา และสถานที่ดังกล่าวด้วย จะขอบคุณยิ่ง

**ขอความอนุเคราะห์**
> ด้วย (ส่วนราชการ) มีภารกิจ/กำหนด … ซึ่งจำเป็นต้องใช้ (สิ่งที่ขอ) …
> ในการนี้ (ส่วนราชการ) พิจารณาแล้วเห็นว่า (ผู้รับ) เป็นหน่วยงานที่มี … จึงขอความอนุเคราะห์ … (ระบุสิ่งที่ขอ วัน เวลา จำนวน)
> จึงเรียนมาเพื่อโปรดพิจารณาให้ความอนุเคราะห์ และขอขอบคุณมา ณ โอกาสนี้

**ตอบรับ / ตอบปฏิเสธ**
> ตามหนังสือที่อ้างถึง (ส่วนราชการ) ขอความอนุเคราะห์ … ความละเอียดแจ้งแล้ว นั้น
> (ส่วนราชการ) พิจารณาแล้ว ยินดีให้ความอนุเคราะห์ตามที่ขอ โดยได้มอบหมายให้ … เป็นผู้ประสานงาน
> — หรือ — (ส่วนราชการ) พิจารณาแล้ว เนื่องจาก … จึงไม่อาจให้ความอนุเคราะห์ได้ในครั้งนี้ ต้องขออภัยมา ณ โอกาสนี้
> จึงเรียนมาเพื่อโปรดทราบ

**ส่งเอกสาร**
> ด้วย (ส่วนราชการ) ขอส่ง (เอกสาร) จำนวน … ชุด มาเพื่อโปรดทราบ/พิจารณา รายละเอียดปรากฏตามสิ่งที่ส่งมาด้วย

**เตือนเรื่องค้าง** (มักทำเป็นหนังสือประทับตรา)
> ตามที่ (ส่วนราชการ) ได้ขอให้ … ภายในวันที่ … ความละเอียดแจ้งแล้ว นั้น บัดนี้ล่วงเลยกำหนดแล้ว ยังไม่ได้รับ …
> จึงขอให้ … ภายในวันที่ … ด้วย

**บันทึกขออนุมัติ** (ถึงผู้บังคับบัญชา)
> ด้วย/ตามที่ … (ความเป็นมา)
> ในการนี้ (ข้อเท็จจริง/ข้อพิจารณา) … จึงขออนุมัติ … ดังนี้ ๑. … ๒. …
> จึงเรียนมาเพื่อโปรดพิจารณาอนุมัติ

## สิ่งที่ห้ามทำ

- ห้ามแต่งเลขที่หนังสือ ชื่อบุคคล ตำแหน่ง เบอร์โทร หรือตัวเลขงบประมาณขึ้นเองโดยไม่มีข้อมูล — ใส่ `[ระบุ…]` แล้วบอกผู้ใช้
