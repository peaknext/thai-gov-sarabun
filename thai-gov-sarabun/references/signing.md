# การลงชื่อและตำแหน่ง (ภาคผนวก ๓)

ที่มา: PDF หน้า 74–79 (`source/annex-3-signing.md` — มีตัวอย่างการมอบอำนาจตามกฎหมายครบทุกกรณี)

## ใครลงชื่อ

๑. **หัวหน้าส่วนราชการระดับกรมขึ้นไป หรือผู้ว่าราชการจังหวัด** เป็นผู้ลงชื่อในหนังสือทุกกรณี นอกจากที่กำหนดใน ๒
   การลงชื่อแทน: ผู้ลงชื่อแทนต้องได้รับมอบหมายหรือมอบอำนาจให้ปฏิบัติหน้าที่แทน รักษาราชการแทน รักษาการแทน ปฏิบัติราชการแทน รักษาการในตำแหน่ง หรือทำการแทน ตามที่กฎหมายกำหนด
๒. หัวหน้าส่วนราชการระดับกรมขึ้นไปหรือผู้ว่าราชการจังหวัด จะกำหนดให้ผู้ดำรงตำแหน่งใดลงชื่อได้เฉพาะหนังสือในหน้าที่ของตำแหน่งนั้นหรือของส่วนราชการในบังคับบัญชา
   และหนังสือนั้น **ไม่ก่อให้เกิดนิติสัมพันธ์** กับส่วนราชการระดับกรมหรือจังหวัด — ผู้ลงชื่อซึ่งเป็นหัวหน้าส่วนราชการต่ำกว่ากรมจะมอบหมายเป็นหนังสือให้ผู้ดำรงตำแหน่งรองลงไปลงชื่อแทนก็ได้

## การพิมพ์ชื่อเต็มใต้ลายมือชื่อ (ข้อ ๓)

- ใช้คำนำนาม **นาย นาง นางสาว** หน้าชื่อเต็ม ในวงเล็บใต้ลายมือชื่อ — `(นายสมชาย ใจดี)`
- ยกเว้น
  - ๓.๑ สตรีที่ได้รับพระราชทานเครื่องราชอิสริยาภรณ์ตามกฎหมายว่าด้วยการให้ใช้คำนำนามสตรี → **ท่านผู้หญิง / คุณหญิง**
  - ๓.๒ มีบรรดาศักดิ์หรือฐานันดรศักดิ์ → พิมพ์คำเต็มของบรรดาศักดิ์/ฐานันดรศักดิ์ไว้ใต้ลายมือชื่อ (เช่น หม่อมราชวงศ์ … ไม่ใช้ตัวย่อ ม.ร.ว.)
  - ๓.๓ มียศที่ต้องใช้ประกอบชื่อ → **พิมพ์คำเต็มของยศไว้หน้าลายมือชื่อ** และพิมพ์ชื่อเต็มไว้ใต้ลายมือชื่อ
    ```text
              พันตำรวจเอก  ..........(ลายมือชื่อ)..........
                          ( สมศักดิ์ รักชาติ )
    ```
    (ใน build_docx ใส่ `"signer": {"rank": "พันตำรวจเอก", "name": "สมศักดิ์ รักชาติ"}`)
  - ๓.๔ กฎหมาย/ระเบียบกำหนดให้ใช้ตำแหน่งทางวิชาการเป็นคำนำนาม → ปฏิบัติตามนั้น (เช่น ศาสตราจารย์ รองศาสตราจารย์ ผู้ช่วยศาสตราจารย์ — เขียนคำเต็ม)
- แนวปฏิบัติที่นิยม (ไม่ได้เขียนไว้ตรง ๆ ในภาคผนวก ๓): ไม่ใช้คำนำหน้าแบบย่อ (นพ. ผศ.) ในวงเล็บชื่อเต็ม ให้เขียนคำเต็มตามสิทธิ์
  และไม่ใส่ "ดร." เพราะไม่ใช่คำนำนามตามกฎหมาย — ถ้าหน่วยงานของผู้ใช้มีธรรมเนียมต่างออกไป ให้ทำตามหน่วยงาน

## การลงตำแหน่ง (ข้อ ๔)

- ลงตำแหน่งของเจ้าของหนังสือ; ถ้าผู้ลงชื่อมิใช่เจ้าของหนังสือโดยตรง ให้ลงตำแหน่งของผู้ลงชื่อ
- ราชการทหารลงตำแหน่งตามระเบียบข้อบังคับและแบบธรรมเนียมของกระทรวงกลาโหม
- **ลงชื่อแทน**: ใช้คำว่า ปฏิบัติหน้าที่แทน / รักษาราชการแทน / รักษาการแทน / ปฏิบัติราชการแทน / รักษาการในตำแหน่ง / ทำการแทน
  แล้วแต่กรณีตามที่กฎหมายกำหนด — ถ้าไม่มีกฎหมายกำหนดให้ใช้คำว่า **แทน** — แล้วลงตำแหน่งของเจ้าของหนังสือต่อท้ายคำนั้น

```text
                         (นายสมชาย ใจดี)
                    รองปลัดกระทรวงสาธารณสุข
              ปฏิบัติราชการแทนปลัดกระทรวงสาธารณสุข
```

## ความหมายของคำที่ใช้เมื่อลงชื่อแทน (สรุปจากตัวอย่างในภาคผนวก ๓)

| คำ | ใช้เมื่อ | ตัวอย่าง |
|---|---|---|
| ปฏิบัติหน้าที่แทน | คณะรัฐมนตรีมอบหมายรองนายกรัฐมนตรี/รัฐมนตรีปฏิบัติหน้าที่แทนนายกรัฐมนตรี เพราะนายกรัฐมนตรีตายหรือขาดคุณสมบัติ ระหว่างรอคณะรัฐมนตรีใหม่ | |
| รักษาราชการแทน | **ไม่มีผู้ดำรงตำแหน่ง หรือมีแต่ไม่อาจปฏิบัติราชการได้** — ผู้รักษาราชการแทนมีอำนาจเต็มเหมือนผู้ดำรงตำแหน่ง (พ.ร.บ.ระเบียบบริหารราชการแผ่นดิน) | "รองอธิบดี รักษาราชการแทนอธิบดีกรม…" |
| ปฏิบัติราชการแทน | ผู้ดำรงตำแหน่ง **ยังอยู่** แต่ **มอบอำนาจ** ให้ผู้อื่นปฏิบัติราชการแทนในเรื่องที่มอบ (มอบอำนาจตามกฎหมาย) — ใช้บ่อยที่สุด | "รองปลัดกระทรวง ปฏิบัติราชการแทนปลัดกระทรวง…" |
| รักษาการแทน | กฎหมายเฉพาะใช้คำนี้ เช่น ตำแหน่งในมหาวิทยาลัย | |
| รักษาการในตำแหน่ง | กฎหมายเฉพาะใช้คำนี้ | |
| ทำการแทน | ใช้ในศาล ตามกฎหมายว่าด้วยระเบียบบริหารราชการศาล | |
| แทน | กรณีไม่มีกฎหมายกำหนดคำไว้ | |

ถ้าผู้ใช้ไม่บอกว่าลงชื่อแทนหรือไม่ ให้ใส่เฉพาะตำแหน่งของผู้ลงชื่อ และอย่าเดาคำว่า "ปฏิบัติราชการแทน/รักษาราชการแทน" ขึ้นเอง
